## 1. 决策与完成目标

用户明确以最终效果为优先，不以改造时间和复用现有实现的比例作为主要取舍依据。本次按完整证据链设计，不局限于修补当前前缀定位函数。

交付目标：回答中的引用能准确指向支持相应结论的教材原文，点击、页码、高亮和裁图使用同一份证据位置。定义、比较、跨页、多段支持、章节总结、表格和公式均有明确处理方式；无法确认的位置诚实降级。

方案选择：

| 方案 | 判断 |
| --- | --- |
| 仅扩大裁图范围、修改首行匹配 | 不能解决论据选择、重复文本和分块来源丢失，不作为最终方案。 |
| 整体迁入某个开源平台 | 平台名称或功能数量不能证明本教材的定位准确率。作为候选方案，只有对照结果证明必要且有效时才采用。 |
| 在本项目重建证据链，直接复用合适的上游模块 | 当前选定。允许重建解析映射、索引和引用协议；每个保留或引入的模块都接受相同验收。 |

当前不开展教学风格、掌握度算法、课程规划或无关界面重构；引用问题必须贯穿的生成、质检、流式发布、历史恢复和前端显示属于本次范围。

## 2. 已确认问题与仍需测量的内容

已通过只读核查确认：

- `knowledge/citation_locations.py` 的心理学分支取检索块 `block_start` 对应段落的前 28 个规范化字符，在 PDF 中寻找一行；该行不一定是回答引用的论据。
- 命中后仅返回行级矩形，截图可能只包含标题，或同一检索块开头的无关定义。
- 双盲案例的原文存在于第2章生成 PDF 第19页末至第20页，但实际引用截图分别展示了方法标题和因变量定义。
- 当前索引有 1,346 个文本块，存在 256 组共享起始段标识的文本块。这是来源粒度风险，不等于已经证明这 256 组全部定位错误。
- 现有结构化段落未直接携带完整 PDF 字符坐标；部分 `page` 字段表示小节起页，不能当作具体论据所在页。
- 回答质检主要面对检索上下文，精确引用位置在后续补齐，尚未形成最终展示内容的完整核验。

尚未测得：全教材定位准确率、各类失败占比、现有模型引用语义准确率，以及上游模块在本教材上的实际效果。不得把单例排查结论写成全量测试结果。

## 4. 目标数据链路

```text
原始教材与版本标识
  → 可定位的 PDF 字符／行／段落及结构化内容
  → 带来源映射的检索上下文
  → 本轮细粒度证据单元
  → 回答中的结论与证据 ID 绑定
  → 原文存在性、结论支持性核验
  → 服务端按证据坐标生成引用、高亮与裁图
  → 最终展示范围核验
  → 原子保存及发布，历史恢复使用已保存证据
```

### 4.1 原文位置记录

至少包含：`document_id`、`document_version`、`source_block_id`、原文、块内字符范围、PDF 页码、每行或字符范围对应的矩形。

- 坐标统一为本项目 0～1 规范化坐标，约定原点、旋转页和可见页面范围；转换过程可测试。
- Word 结构化正文提供段落语义，当前展示的生成 PDF 提供视觉位置。两者需有可核验的对应关系，不能由小节起页替代。
- 检索切块、重叠、父块扩展之后仍保留各段来源，跨段或跨页用位置数组表达。
- 规范化只用于匹配，并保留原始位置反向映射；不得通过删除数字、负号、公式符号等把不同含义的文字当成同一引文。
- 不同文档、版本或章节不得拼成连续原文。PDF 重生成后按新版本重建位置，旧坐标不得直接复用。

### 4.2 本轮证据与回答绑定

证据记录至少包含：`evidence_id`、检索来源 ID、文档版本、原文引句、原文范围及位置数组。显示编号 `[1]` 是本轮展示编号，不是永久 ID。

模型只允许选择服务端提供的证据 ID。模型提出的引句须实际存在于相应证据中；页码、矩形、文件路径由服务端解析，不能由模型生成后直接采信。

- 一条结论可使用多条证据；同一证据也可被多处使用。
- 先从相关上下文选择证据，再组织回答；质检发现缺失支持时，重新选择或补检索，不能事后任意找一段相似文字补上编号。
- 相关性分数或字符串匹配成功都不等于结论被原文支持，语义支持性须单独核验。
- 自编辅助例子明确标注来源性质。其依据可引用教材定义，但不能把虚构情境标成教材原句。

### 4.3 定位状态与展示

| 状态 | 判定 | 展示 |
| --- | --- | --- |
| 精确证据 | 引文、字符范围和 PDF 位置均通过核验 | 展示原文引句，跳转并高亮完整范围；需要时分多张裁图。 |
| 页级来源 | 来源页已核实，精确文字范围未核实 | 明确标注“页级来源”，只跳页，不冒充精确高亮。 |
| 小节级来源 | 仅能核实所属小节 | 标注“小节位置”，不能用标题截图充当支持结论的原文。 |
| 无法定位或版本失效 | 来源无法确认或版本不一致 | 给出明确状态，不显示精确截图，不使用旧坐标。 |

语义证据不足时修订或拒绝对应结论；语义证据充分、几何定位不足时允许带明确降级标记的来源。两种失败不能混为一谈。

## 5. 实施阶段与交付门槛

### 阶段一：固定基线与回归样本

- [ ] 保存双盲这次错误的引用、裁图、原文和预期位置，作为必过回归。
- [ ] 覆盖全部 11 章，建立 100 个固定场景：定义 20、比较或多段支持 20、跨页 20、章节总结与重复表述 15、表格/公式/图注 15、歧义或无可靠位置 10。
- [ ] 给样本标注支持原文、允许的证据组合、页码范围、预期高亮和允许降级状态；不能以待测模型自己的答案作为真值。
- [ ] 固定 70 个开发场景、30 个留出场景；留出结果不用于反复调阈值。
- [ ] 测量当前检索召回、语义支持、定位、裁图展示四项基线，分别记录失败。

交付：基线报告与样本清单。没有基线，不宣称后续改造提升了多少准确率。

### 阶段二：构建原文位置索引

- [ ] 解析 PDF 文字与字符/行级坐标，将结构化教材段落关联到实际位置。
- [ ] 处理换行、段落拆分、跨页、重复文字、页眉页脚、页面旋转和不可提取文本。
- [ ] 对齐失败单独登记；确需 OCR 或版面解析器时再引入，并比较实际样本效果。
- [ ] 修复切块与扩展中的来源映射，不再只保存共享起始段作为精确定位依据。
- [ ] 在独立构建目录生成新索引与版本清单，不直接覆盖正在服务的索引；核验成功后再切换，并使相关缓存失效。

交付：带坐标的全教材证据索引、构建报告、可重复执行的构建入口和可回滚切换方式。

### 阶段三：接入证据选择与引用核验

- [ ] 按第3节核验、抽取上游模块并补齐许可证来源记录。
- [ ] 大块上下文保留用于理解，小证据单元提供给生成与核验，二者通过来源映射关联。
- [ ] 将结论绑定到证据 ID，验证 ID 所属教材、版本和本轮允许范围。
- [ ] 精确匹配优先；规范化匹配保留反向位置；重复匹配结合段落、页面及前后文消歧，不能直接取第一次出现。
- [ ] 语义核验针对绑定的小证据，不能只检查整章或大块中是否存在相关内容。
- [ ] 证据不足按现有有界修订流程处理；保留仅提示、作答证据资格和教学质量约束。

交付：普通聊天、PDF选区、指定小题辅导共用的证据协议，以及错误引文、无效编号和错误结论的拦截用例。

### 阶段四：引用展示、发布与历史恢复

- [ ] 点击、页码、高亮、截图全部读取同一证据记录，不由前端再按文字重新搜索猜测。
- [ ] 跨页或不连续证据分别展示，禁止截一大张无关区域来掩盖定位不准。
- [ ] 显示简短支持原文与定位状态，用户可展开对应上下文；局部引句不能遮蔽否定、例外或前提条件。
- [ ] 最终裁图对应范围必须包含目标引文；文字匹配失败或几何异常时降级，不能仍标“精确证据”。
- [ ] 精确引用是发布的必要附件，应与已核验文字一起保存并发布；可选图解仍可随后补充。
- [ ] 兼容 SSE、重放、断线、刷新、删除与账户切换。保存证据随对话受同一删除/版本保护，不能由迟到结果补回。
- [ ] 旧历史缺少精确证据时保持可读，明确显示旧来源粒度；不得用新版本坐标伪装成旧回答的原始定位。
- [ ] 检查现有选区最多 80 个矩形、文本 4,000 字符等限制；引用范围过大时拆分为多个合法证据，不静默裁掉后半部分。

交付：可见浏览器操作证据，覆盖桌面、移动端、刷新恢复及异常状态。

### 阶段五：全量对照与发布判断

- [ ] 同一套固定场景比较当前实现、上游候选与最终方案。只有测得效果支持时才决定保留哪个模块。
- [ ] 100 个场景全量真实模型执行；选定的 30 个高风险场景各额外重复两次，检查随机生成造成的引用漂移。
- [ ] 留存每条结论、证据原句、位置、实际截图、降级原因、重试次数、调用数和耗时，不能只保存“通过”标签。
- [ ] 逐条检查留出集和全部失败；人工复核与机器核验分别标注，无人工或教师复核时不得称为专家认可。
- [ ] 达到第6节门槛后才切换默认引用链路；未达标按失败类型继续修正，不能删失败样本或把更多结果降级来美化精确率。

交付：新旧对照报告、剩余失败清单、启用/回滚说明及源码复用清单。提交和 push 不属于本次“写计划”的授权范围。

## 6. 验收标准

以下为拟定交付门槛，不是已取得的测试结果。

| 指标 | 门槛与计算口径 |
| --- | --- |
| 双盲已知错误 | 全部修复：定义引用直达定义全文；两类控制的解释展示对应证据；跨页内容不缺失。 |
| 结论与证据的语义对应 | 可核验结论中，证据正确支持结论的比例 ≥95%；另列错误因果结论、否定/条件遗漏等严重错误，发布集不得存在已知严重错误。 |
| 精确定位准确率 | 所有标为“精确证据”的结果中，文档、版本、页码与目标原文范围均正确的比例 ≥98%。 |
| 精确定位覆盖率 | 人工基准确认可精确定位的正例中，最终提供正确精确定位的比例 ≥95%；降级和拒绝计为未覆盖，防止靠不定位获得高准确率。 |
| 高亮与截图 | 覆盖完整支持文字且无关键条件丢失；不能只含标题、错误定义或整页替代精确定位。记录额外无关文字与遗漏，不能只检查页码。 |
| 负例与歧义 | 固定负例集中，虚构引文、错误版本及未消歧重复文字不得被标为精确证据。 |
| 发布与数据保护 | 删除、取消、账户隔离、版本变化、请求重放与图解迟到场景全部通过，不产生重复证据或恢复已删除数据。 |
| 稳定性 | 单次与重复运行分别报告准确率、覆盖率及失败；不能只挑选成功的一次展示。 |
| 性能 | 报告新旧调用数、重试率与首个已核验答案耗时的 P50/P95。准确性优先，不在未测量前承诺固定提速或时延。 |

样本规模有限，达标只表示覆盖范围内通过；教师审核、OCR教材与未来教材版本需另行注明验证范围。
