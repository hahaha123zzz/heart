# 原生对话循环受限接入

日期：2026-10-19。保留现有页面和心理学教学链，将教材回答与 PDF 选区讲解接入固定副本的原生 AgentLoop。此阶段是可独立关闭的试点，不改变默认运行配置。

## 复用范围

直接继承 AgenticChatPipeline，执行上游 AgentLoop.run；工具 schema、调度、工具结果回填、多轮上下文、预算保护、输出截断续写、思考过滤和结束协议均来自上游。没有另写探索/回答循环，也没有修改 vendor。

宿主继续提供已核验教材、历史、学生状态、教学计划、提示限制和回答预算。普通回答与 PDF 选区共用同一入口；路由、证据充分性和质量检查的 JSON 调用仍走已有生成网关。最终正文仍须经过原来的质量、证据编号、教材版本与几何引用核验；TaskService 继续决定保存、取消、删除、幂等与恢复。

## 边界与实现

- 新增受共享凭据保护的 POST /internal/heart/agentic，沿用已有消息、模型白名单、图片和参数校验；另接收宿主本轮证据文本，最多 100,000 字符。浏览器不能直接指定工具、密钥或原生身份。
- 每请求创建独立 ToolRegistry，只注册 read_current_evidence。它不接受模型参数，仅返回本轮固定教材证据；首轮必须调用，未实际读取证据的结果拒绝发布。响应携带证据 SHA-256，宿主验证回执。
- 使用上游 ContextVar 配置模型，finally 恢复作用域。工具、证据及模型历史仅在请求内存中，StreamBus 不保留事件历史。跳过上游通用聊天入口的自动磁盘工作区、外部工具及记忆装配；不向原生会话保存问题、回答或引文。
- 上游默认为图片、工具不兼容提供降级重试。这里覆写传输入口，保留原生流消费，但拒绝移除图片或工具重试。临时传输故障复用原生有限重试，参数和证据保持不变；重试耗尽、非正常结束或持续截断均拒绝发布，不能用原生兜底文字冒充成功。
- 普通生成网关也复用 Provider 的一次临时故障重试（延迟 0.5 秒），仍禁止图片降级，且全部尝试共用原总期限；未改宿主模型或增加请求密钥。
- 探索预算 2 轮，加上原生收敛与最终回答最多 6 次模型请求，总期限沿用宿主 timeout，上限 180 秒。中间草稿、工具正文和隐藏推理不送学生页面；只返回最终正文与有限的次数、摘要回执。
- 直接传递宿主 ReplyBudget.maximum；用原生 finish_instruction 钩子检查完整字数，超长要求重写压缩，二次仍不满足则拒绝结束。宿主原质检继续独立检查，不能截断字符串绕过预算。
- 回合投影等待期限与既有会话绑定对齐为至少 25 秒，避免本机文件扫描变慢时在原 3 秒期限内误报失败。错误仍返回 unavailable，原回答不回滚，重发仍按原幂等规则恢复。

发现路由虽有正确提示词，仍可能把“不要编造数据”输出为 no_full_answer。共用 build_execution 增加有限校正：明确要求解释/说明/比较且仅有准确性否定句、没有仅提示/只说思路等范围限制时，去掉误加的提示约束；服务端图形 hint 范围在后续仍优先。增加三个正反例，黄金公式案例也必须验证完整回答范围。该校正不替代现有语义路由。

宿主取消和删除仍由原 TaskGuard 阻止结果保存；尚未把取消信号传到独立 worker，已经发出的模型请求可能运行到其总期限。不得把这个边界描述为跨进程即时取消。

read_current_evidence 复核的是宿主已经检索并绑定的教材，不扩大可引用材料集合。这一轮尚未开放自主全库补查、任意文件、联网、exec、笔记和外部插件；这些需要分别对齐来源、权限与删除语义，不能因继承了原生循环就视作已接入。

## 使用与回退

在宿主和 worker 使用的本机环境中配置共享凭据，启动 worker，并同时设置 DEEPTUTOR_LLM_ENABLED=1、DEEPTUTOR_AGENTIC_ENABLED=1 后重启宿主。仅第二个开关开启时明确报配置错误；显式带教材证据的讲解调用才进入循环。LLM_MOCK=1 仍完全本地模拟，不构成接入验证。

将 DEEPTUTOR_AGENTIC_ENABLED 改为 0 并重启宿主，即恢复已有单次 Provider 生成入口；不改教材、数据库和页面。.env.example 中所有 DeepTutor 执行开关继续为 0。本阶段未改实际 .env。
