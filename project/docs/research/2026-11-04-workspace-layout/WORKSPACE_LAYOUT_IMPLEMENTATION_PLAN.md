## W4：首次建议与预制提示词

展示规则：

| 触发 | 行为 |
| --- | --- |
| 新打开标签页、空白对话、尚未隐藏 | 显示建议 |
| 教材收起 | 建议放在输入框下方 |
| 教材展开 | 同一组建议移到输入框上方 |
| 点击任一状态下的叉号 | 两种状态都隐藏 |
| 首次有效发送用户消息 | 立即隐藏，不等待模型返回 |
| 仅点击建议、尚未发送 | 填入草稿，保持可编辑 |
| 首次消息发送失败 | 继续隐藏，保留重试能力 |
| 切换、新建对话或展开教材 | 不重新显示已隐藏建议 |
| 同标签刷新 | 保持已隐藏 |
| 关闭标签后重新打开 | 可重新显示 |
| 页面恢复已有对话 | 隐藏建议，优先展示正在进行的对话 |

实现：使用按课程和学生隔离的 sessionStorage 标记，不用 localStorage 永久关闭，不按会话 ID 重置。建议块复用一个 DOM 实例和一个关闭状态。

预制提示词方向：

| 建议文案 | 提示词要求 |
| --- | --- |
| 一起安排今天的学习 | 指定当前教材或小节；读取真实学习状态；给目标、重点和步骤；只补问缺失信息；用户确认后开始 |
| 从当前教材继续学下去 | 参考当前位置衔接已讲内容，由现有导航决定下一目标；无历史时从基础开始，不虚构已学内容 |
| 回顾之前学过的内容 | 基于真实记录推荐复习范围和原因；没有记录时先确认范围，不伪造到期复习或掌握度 |

验收：两种布局位置正确；叉号、首次发送、刷新、新建会话和来源切换均符合上表；点击建议不直接启动模型请求。

## W5：视觉收敛与排版

工作：

1. 使用白色内容面、轻灰侧栏、细分隔线及留白，减少装饰性色块和外层方框。
2. 对话列表为紧凑文本行，助教正文沿用正常文档排版；仅在任务状态、题目和明确操作需要分组时保留边界。
3. 教材收起时正文和输入框最大宽度约 800px；欢迎语和建议根据内容排列，避免固定定位遮挡消息。
4. 建议颜色比正文浅，但保持可读对比度；鼠标悬停和键盘焦点可辨识，不能仅靠颜色表达状态。
5. 短屏、长标题、长回答、公式和表格均不导致整体横向溢出；尊重 reduced-motion。

验收：对照用户参考图完成一次桌面与窄屏批量截图检查，集中修复后复核一次。
