# 学习工作台布局调整

日期：2026-11-04。依据：用户提供的 ChatGPT 桌面截图和本次明确要求。

## 布局

桌面从左到右为：图标导航（约 60px）、对话列表（约 240px）、教材阅读器、学习对话。

“继续学习”和“教材阅读”合并为“学习”。图标导航保留学习、练习与复习、学习记录、设置入口。默认只显示现有 SVG 图标，鼠标悬停或键盘聚焦时显示功能名，保留 aria-label 和明确焦点。

对话列表显示新对话和真实历史会话标题，当前会话有轻量选中标识。切换会话恢复对应历史与待处理任务，不复制对话或学习路径；生成过程中禁止切换，未发送草稿及待答任务沿用现有确认保护。历史必须按实际 session_id 分组，不把单条消息伪装成独立会话。实现前核对现有历史接口是否返回会话身份，缺失时仅补充最小列表接口。

打开学习页默认收起教材。教材展开时保持现有教材与对话分栏、拖拽比例和阅读功能。章节目录入口保留在教材区，避免新对话列表占用原章节目录后失去教材导航。

教材收起时隐藏阅读面板及分隔条，对话占满余下空间，正文和输入框居中，最大宽度约 800px。空对话显示简洁欢迎语和输入框；已有消息保持正常纵向阅读。收起和展开按钮始终可找到。

## 状态与阅读器

教材收起只改变面板可见性，不卸载阅读器、不创建新的 React root、不重新请求整份 PDF。保留页码、缩放、选区与高亮；展开后通知现有阅读器适应容器尺寸。引用跳转到教材时自动展开阅读器，再沿用现有引用定位。

布局状态沿用 Workspace 的存储隔离键，不引入另一套学生或会话身份。保留现有移动端内容/对话切换；窄屏不挤入四栏，对话列表由按钮打开并支持关闭和键盘操作。

## 首次学习建议

学习、继续学习、复习三类建议使用浅灰文字和轻量图标，不套卡片。教材收起时位于输入框下方，教材展开时移动到输入框上方，复用同一组 DOM 与可见性状态。

建议区在两种布局中都有叉号。关闭其中任意状态下的建议后，另一状态同步隐藏。本次打开期间首次发送用户消息后也隐藏；切换会话、展开教材和新建对话不重新显示。以当前标签页打开周期为边界，使用 sessionStorage 保存隐藏状态，刷新后仍隐藏；关闭标签并重新打开时可重新显示。恢复已有会话时如已有聊天记录，不用建议占据正在进行的对话。

建议点击后只填入可编辑的预制提示词，不自动发送。提示词依据当前教材和阅读位置提出学习安排或复习请求，不把固定建议伪装成对真实学习状态的诊断，不自行宣称已读记录、已掌握或复习到期。需要个性化推荐时由已有对话链路读取实际状态后回答。

## 视觉

使用白色内容面、轻微灰色侧栏、细分隔线和留白。功能按钮透明底，悬停时轻量反馈，避免整块高饱和背景。对话列表使用紧凑文本行，不套卡片。助教正文去除外层装饰性方框，保留需要清晰识别的题目、确认操作、错误提示和状态。

删除左上角“搜索教材或提问”表单及其事件绑定；不删除后端教材检索能力。

## 影响范围

- frontend/index.html：图标栏、会话栏、章节目录位置、教材折叠入口、删除搜索表单。
- frontend/workspace.css：四栏结构、收起后的居中对话、轻量视觉和响应式。
- frontend/workspace.js：教材可见性、布局持久化及尺寸恢复。
- frontend/app.js：真实会话列表、会话恢复、引用自动展开、移除搜索表单绑定。
- 会话列表接口与测试：先复用已有服务；如字段不足，只补必要的会话身份和标题。

当前上述前端文件均有其他窗口未提交修改。实施必须基于现状逐段修改，不覆盖整文件、不提交其他窗口改动。

## 验收

1. 桌面展开四栏顺序正确，原教材阅读、滚动、选区与提问可用。
2. 收起后正文与输入框居中，无残留空白教材列；恢复后页码和缩放不变。
3. 图标在悬停和键盘聚焦时显示名称；所有按钮可通过键盘使用。
4. 新建和切换真实会话、刷新恢复不串历史，生成中不能切换丢失输出。
5. 收起教材后点击引用能展开并跳转；教材折叠不触发重复文档加载。
6. 左上角搜索入口消失，页面初始化无 null.addEventListener 异常。
7. 桌面和 390px 窄屏无横向溢出，真实截图检查布局与留白。
