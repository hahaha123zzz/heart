# 教材原图“返回教材”定位修复计划

日期：2026-10-23。状态：方案已编写，尚未实施、验收或部署。

## 1. 目标与已核对根因

点击回答中原图的“返回教材”，打开同一教材版本中该原图实际所在页，并将图片区域滚入视口、高亮。无法可靠定位时，明确说明只能打开小节；失效来源禁止跳转。

本计划基于 main `0a5790cbfb6195e49d15cb200605cac77ab0cd1a`。当前 8000 使用 `2ae1e5f` 固定导出，加已登记的阅读器滚轮构建覆盖，不能将运行目录称为纯 `2ae1e5f`。实施前重新核对分支、运行目录、哈希和其他窗口修改。

已直接读取运行副本教材及代码核实：

- 图 1-2 是 `image-01-0004`，资产 SHA256 为 `b1341a85b7600beb23c829b4723cb5fac418403049fd60d06e605e8a84e7b384`，章节 1、小节 2、解析块 168。
- 当前生成阅读版 PDF 中，图注“图1-2 遗忘曲线”在第 14 页；第二节起点为第 9 页。页码为生成 PDF 页码，不是纸质书印刷页码。
- `knowledge/answer_media.py:selected_media` 为每张图生成 `rects=[]`、`location_status='section'` 的引用，没有图所在页码和区域，且 text 使用检索原文而非图注专用定位信息。
- `frontend/app.js` 只选中所属小节，再传递上述空区域引用；阅读器没有精确区域就落到小节起点。因此该图跳到第 9 页，而非第 14 页。
- 现有真实媒体浏览器测试只断言正确 chapter/section，没有断言目标图片在视口中。

这证明了定位协议缺失；不据此断言所有图片的小节登记都正确，需要逐项扫描。

## 2. 方案选择

| 方案 | 取舍 |
| --- | --- |
| 统一解析真实 PDF 图片位置（采用） | 新回答与历史点击共用；保留来源校验；覆盖同类问题，不需重写历史 |
| 仅硬编码图 1-2 的第 14 页 | 无法覆盖换版、同类图片、裁图与缩放，不采用 |
| 只把按钮改为“打开小节” | 可作为定位失败时的诚实降级，不能满足准确返回原图的主要目标 |

优先复用 `source_visuals` 的资产身份、`pdf_reader` 的版本/坐标约定和已有 `figure_locations` 校验模式。现有离散数学人工位置模块不能未经核对直接用于心理学：心理学加载分支目前不经过该模块，其批准状态也不能用于批准 pending 资产。

## 3. 实施阶段

### P1：建立只读定位解析与全书扫描

1. 核对所有调用方、PDF 图片结构及当前解析块→资产映射，先给图 1-2 写能复现“实际在第 14 页、现协议无区域”的失败用例。
2. 在知识层集中解析原图位置：输入资产 ID、资产哈希、document_id 和保存版本；读取前验证资产、源文档和实际 PDF 哈希。
3. 优先使用 PDF 中嵌入图片与原资产解码像素的可验证对应，返回归一化区域。文件编码不同不直接判定为不同图片；不得只靠相近尺寸、出现顺序或图号字符串绑定。
4. 若图片转码或拼图导致无法直接匹配，只有经核对的映射可提供精确区域；图注匹配只能作为明确标注的图注定位，不伪称图片区域。正文提及“图1-2”不等于图注。
5. 同一资产多次出现时，只有原解析块/小节等可靠信息能够消歧才定位；仍不唯一则返回 ambiguous，不默认取第一个。若发现资产小节与实际位置不符，登记问题，禁止静默改写学习目标或教材清单。
6. 扫描全 11 章可用原图，按精确原图、仅图注、仅小节、不唯一、失效、缺图分类输出审计清单，记录 document/version/asset/hash/page/rect/匹配依据。教材原件、正式索引及候选均只读。

定位缓存如有必要，以 PDF 版本和资产哈希为键，放在可丢弃运行缓存中；换版或文件不符立即失效，不写冻结候选或正式数据库。

### P2：新回答与历史点击共用接口

1. `selected_media` 接入 P1 结果，新回答保存可靠的原图位置，不再无条件生成空区域引用；继续保留 image_refs 身份、像素接收标记和现有模型/质检流程。
2. 增加最小只读原图定位接口，建议 `POST /api/course/figure-location`，挂入现有 `web_api.py` 路由，不改 main.py。请求必须携带保存的资产 ID、SHA256、document_id、version；服务端按登记解析，拒绝客户端路径与未经核验的坐标。
3. 响应沿用现有 selection_ref 坐标结构，另给定位状态与依据。建议状态为 exact、caption、section、ambiguous、stale、unavailable，具体字段在实现前核对现有调用方并固定。精确结果提供 page 与 rects；区域使用完整生成 PDF 坐标，由阅读器现有 page_map 转换，防止重复换算。
4. 历史回答点击时使用保存身份调用同一接口，在同一版本内解析导航位置，仅用于本次显示，不改写历史记录。缺少资产身份、哈希或版本时不得套用当前教材补齐为“已核验”。
5. 已失效版本保持失效，不升级为当前版本；定位成功也不改变 pending、模型是否收到像素、证据审核状态、发布 readiness 或教材事实可信度。
6. 只改原图点击处理及必要的按钮状态：精确时“返回教材”，仅小节时“打开所在小节”并提示无法精确定位；图注定位明确说明。请求失败不使用过期位置兜底。处理快速连续点击的晚到响应，不能覆盖后一次导航。

不改通用 citation-state 的既有语义，不给普通文字引用引入额外查图开销。需修改共享 web_api.py/frontend/app.js 时，独立提交并列明调用方，保留其他窗口修改。

### P3：离线及隔离浏览器验收

| 用例 | 必须观测的结果 |
| --- | --- |
| 图 1-2 主复现 | 点击后打开生成阅读版第 14 页，原图区域实际进入视口；不能只验证小节 2 |
| 新回答与历史回答 | 新记录具备可靠位置；旧的空 rects 在保存身份完整时同版本解析成功；无须重新生成回答 |
| 其他章节及多图 | 全书扫描留清单；抽取多个章节、不同页面位置实际点击；两张图各自定位，刷新后仍对应原图 |
| 原图、图注和正文提及 | 正文同号提及不能冒充图注/原图；caption 状态与 exact 区分；同图多处出现不随意取首项 |
| 坐标与阅读器 | 页面缩放、页面拆分映射、已打开其他章节、滚轮翻页后点击，仍返回正确页与可见区域 |
| 失效及输入缺口 | 旧版本、错误哈希、缺资产、缺身份、定位歧义、接口错误分别受控拒绝或诚实降级，不跳错图 |
| 异步与恢复 | 快速连点不同图片，最后一次点击生效；刷新后可再次定位，不新增模型生成 |
| 学习与媒体回归 | 点击不推进 Q5 目标/掌握度，不保存新问答；上标引用、原图展示、同图质检及 pending 标签保持正确 |

先跑定位模块和接口的有意义单元测试，再跑原有 answer_media/source_visuals/来源失效相关测试，最后跑隔离浏览器。浏览器断言实际 PDF 页码、目标区域与视口相交及高亮，不以 toast、HTTP 200、页面打开代替成功。

纯导航无需真实模型调用。新回答保存链路可用确定性模型夹具测试，并明确标注；若追加真实模型媒体回归，必须单列实际调用及结果，不冒充模型验收已完成。

每项记录命令、最终提交 SHA、实际运行文件哈希、接口输入输出、截图及通过/失败；失败和未解决的人工确认条目保留，不为全绿强行绑定。

### P4：交付与运行版本更新准备

1. 各小阶段仅提交本任务文件并 push；验收最终以同一已提交版本重跑，保留其他工作区已有修改。
2. 提交全书位置审计清单、接口说明、浏览器证据和验收矩阵，区分已实现、离线通过、浏览器通过、未完成。
3. 当前 8000 不读主工作区。准备包含已交付滚轮阅读器的新完整导出，列明后端、前端及构建哈希，不能只改主工作区就宣布用户已生效。
4. 先隔离验证，再给出具体启用与回滚命令、进程身份和新一致性备份；是否执行正式切换按当时用户授权及运行状态确定。写计划本轮不切换、不覆盖运行文件。
5. 回滚恢复上个已核实运行版本及其已登记阅读器，沿用最新学习库，不恢复旧备份覆盖新学习数据；定位缓存可废弃，候选和索引不动。

## 4. 范围与完成标准

预计触及知识层定位代码、answer_media.py、web_api.py、frontend/app.js、必要媒体展示代码及对应测试/文档。阅读器现有坐标接口若已足够，不改源码或重建产物；确需改动时连同源码、构建产物和滚轮回归一并交付。

不扩展 LightRAG 检索、Q3/Q5 编排、题库、评分或第二套阅读器；不重建索引、修改教材、数据库历史、候选核心、staging/ready=false；不把位置匹配当作教师审核。

完成标准：图 1-2 及隔离样本实际准确返回；全书同类问题有可复核分类清单，所有歧义和缺口明确保留；历史不伪升级；学习位置不被推进；交付提交和运行版本可核对。全书扫描完成不等于全书每张图均已人工审核或均可精确定位。
