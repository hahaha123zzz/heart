# 对话质量基线与对照

质量比较优先于整套工具铺开：Q0保留已有基线，Q1开始对本项目代码迁入前后逐批对照，Q2—Q6持续验证。整套能力范围保持不变，首个里程碑优先改善现有页面中的对话。复用已有9类心理学黄金问题，新增连续对话场景见项目 tests/data/deeptutor-conversation-quality.json。本次仅修订计划，未运行新旧在线对照，不填写推测分数。

| 维度 | 必须观察的行为 | 不通过示例 |
| --- | --- | --- |
| 回应任务 | 完整回应明确子问题，符合提示/完整解答要求 | 把不要编造数据当成只给提示，漏掉第二个对象 |
| 教材忠实 | 事实与当前版本原文、图像及引用相符 | 标注存在但不支持结论，把参照点不同推断成结果必然不同 |
| 多轮一致 | 识别追问所指，允许用户纠正，延续原任务 | 简化上一解释却改答末尾检查题；重复错误或擅自换题 |
| 教学适配 | 讲解深度和节奏符合本轮要求 | 没听懂就直接出新题；仅提示泄露完整答案 |
| 澄清交互 | 仅在信息必要缺失时追问，答复后继续原任务 | ask_user 答复触发新的无关生成；恢复后丢失原问题 |
| 历史与偏好 | 区分学生事实、助教草稿和风格偏好，撤销有效 | 旧助教解释被当成学生已掌握，删除后摘要复活 |
| 可用性与成本 | 实际首个有效输出、总时间、模型调用/工具次数和失败状态 | 用快速进度提示冒充有效答案；省略失败样本 |

## 比较办法

同一教材版本、同一问题/对话序列、相同模型与设备，分别运行本项目迁入前与迁入后的实际链路。记录必须证明迁入模块、本项目上下文及对应检索/工具实际生效，不以委托完整 DeepTutor 应用或独立 worker 的结果代替项目验收；历史试点只作参考。记录所有尝试、失败、修订和人工不接受项，不能把不同版本的结果拼成一次完整绿色运行。

每个样本保存实际引擎/提交、模型、教材与索引签名、对话顺序、答案、来源、执行状态、核验/发布状态、耗时及调用次数；敏感原始产物只留 .runtime。报告注明自动判断、人工原文核对、待教师审核，模型质检通过不单独构成事实正确证明。

目前不设无基线的“提高百分比”。M1（Q1）的退出条件是当前页面内的普通对话和追问已使用迁入模块，本轮必需事实/范围/引用检查通过，有可复核的改善且未掩盖退化；M2（Q3）补齐循环/澄清/恢复，M3（Q6）按整套矩阵验收。性能与费用分别报告，全教材、评分可靠性和生产并发随对应阶段验证。
