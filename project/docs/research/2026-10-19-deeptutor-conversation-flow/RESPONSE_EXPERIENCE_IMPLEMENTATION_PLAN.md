## 1. 交付目标与边界

1. 模型正文生成过程中即可阅读；生成、核验、保存状态准确。
2. 正文下不再展开来源清单，相关文字旁显示数字上标；点击后查看证据或打开教材。
3. 需要图表时在答案中显示有效教材原图/表格，模型需要读图时确实收到像素，核验与保存完整。
4. 公式、表格、标题、列表、中文强调和长内容正常显示，回答结构及长度匹配用户任务。

沿用现有网页、阅读器、LLMClient、任务身份、课程版本、学习数据库、SSE 和已迁入的 Markdown。LightRAG 后续继续输出同一来源/媒体契约，本专项不等待全书建图、不改其检索内部实现。

覆盖普通聊天、Q5 讲解/计划展示、PDF 选区问答和练习帮助。它们有不同入口，逐项验收；普通 Q3 通过不能代表全部通过。

本专项不实现正式评分/复习，不替代 Q5 全书计划生成器接线；但详细计划已有数据必须能完整显示，不被所有任务统一的短回复限制截断。

## 4. 事件、来源与媒体契约

沿用现有 SSE，以下新增事件为实施契约，不是已经存在的功能：

| 事件 | 行为 |
|---|---|
| `progress` | 保留现有阶段进度，与旧消费者兼容 |
| `answer_delta` | 带 task_id/task_revision/answer_id/round_id/seq/text，只追加对应草稿 |
| `answer_replace` | 同一答案身份、更大的 seq、完整 text；整段替换，空字符串也有效，可撤回草稿 |
| `answer_state` | 同一身份和 seq，状态 generating/checking/saved/rejected；不触发额外模型生成 |
| `answer` / `done` | 保留完整结果，覆盖为权威正文/来源/媒体，不能再追加一次完整 reply |
| `error` | 保留安全错误信息，草稿按失败规则清理/撤回 |

seq 在同一 answer_id 的新增正文/状态事件内单调递增。request 重连不新建答案身份；task_revision 必须有效。拒绝轮先撤回再展示修订轮，不能把工具调用轮草稿当正式答案。最终保存内容、done、页面及历史一致。

新上标使用消息内引用编号对应最终 evidence，保留来源与版本检查。流式映射尚未完成时不允许打开猜测的来源；最终编号变化通过 answer_replace/done 同步更新。

媒体继续复用 SourceRef.image_refs/ToolResult.model_message 等现有字段；在源记录中补齐必要身份，不因换检索后端而改变课程或资料版本。正文图表只从本条回答的有效媒体集合选择，原图来源与模型输入对应一致。
