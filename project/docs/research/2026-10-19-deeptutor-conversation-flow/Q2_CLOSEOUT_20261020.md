## 实际改动

- **Q2.9**：沿用已有证据包发布协议和实际 PDF 核验；一次发布中的引用共用同一个来源发布身份。目录、源 DOCX、资产映射或原图字节变化时，新协议历史仅生成失效展示投影，保留原编号、原版本和原始保存记录；缺少证据协议的旧历史不补造验证字段。
- **Q2.10**：`previous_cursor` 从最新有效任务收据刷新教学状态，不暴露题目答案。普通解释后“我懂了，下一部分 / 下一步 / 继续 / 接下来”走教材下一标题；仍在当前教学步骤时继续同点；上一轮明确出题时先待答；带选项的真实作答交回已有作答路由。显式下一知识点允许浏览推进，但不记录掌握或覆盖。
- **同点与重述分离**：`下一步推导 / 继续这个例子` 保持目标，并要求承接历史中尚未完成的部分；`没听懂 / 换说法` 重述当前目标。前者使用导学表达预算 360 字，后者保持短回复 260 字，不截断回答。
- **路径绑定**：普通回答与圈选回答必须有当前文档身份、PDF 版本和真实文件哈希；再匹配真实标题范围。正分并列和零命中均澄清，取消按靠后位置猜选。不唯一时可回复候选标题；缺版本时可说明章号，无需重新圈选。跨小节澄清每个涉及小节各给一个候选，不截掉后续小节。
- **版本与原图**：导航读取当前目录与 PDF 清单；路径版本包含目录、正文、源文件、原图登记、原图文件字节和 PDF 定位记录。缓存原图发送前重新核对源 DOCX、节/块位置、occurrences、标签、审核状态和资产字节；旧缓存映射不再继续使用。课程处于 staging、图片待审核等状态仍如实报告，不自动发布。

## 稳定接口与兼容

| 接口 | 本轮变化 | 调用方与兼容方式 |
| --- | --- | --- |
| `resolve(message, *, cursor=None, reader_location=None, activity=None)` | 只新增可选 `activity`，默认读取 `cursor.activity`；增加 `continuation_action` | 当前 TaskService 原调用保持不变；Q3 可显式传入当前教学活动。`None` 仍表示交普通识别，`ready/clarify/complete` 保持原义。 |
| `previous_cursor(recent, memory, student_id)` | 原字典上附加 `activity={goal, awaiting_answer, within_point}` | 当前 TaskService 已调用；只读取最新有效收据，不修改任务库。Q3 不应把旧 activity 当作永久状态，应每轮刷新。 |
| `continuation_action` | `continue_current / rephrase_current / await_answer`，非必填 | Orchestrator 对继续和重述分别组织任务范围、证据问题；表达预算读取相同动作。Q3 可复用该动作，不能据此推断评分。 |
| `bind_result(result)` | 返回形状不变；无版本、换版和匹配并列时更保守 | 当前 TaskService 在回答提交后绑定；上游应保留 `selection_ref.document_id/version/chapter_id/section_id/quote/text`。不会写回或升级旧引用。 |
| `outline / validate / read_target` | `id`、`position` 与 `TextbookChunk/source_spans` 形状保持；新增 `source_version/source_valid`；`version` 仍为不透明字符串但计算范围扩大 | 旧游标版本会明确失效，不能只按同名标题或相同位置静默续用。重新指定章节或在有可靠当前证据的新回答后绑定；不迁移正式数据。 |
| `course_release.binding/validate` | 默认刷新发布身份和原图缓存；新增清单摘要与章节源文件身份 | 引用发布、历史投影及 Q3/Q5 来源绑定沿用原接口。重复校验时不能把缓存 snapshot 当作当前版本。 |
| `references_for_display` | 增加来源发布身份失效检查，仍只返回深拷贝 | 当前历史与任务重放入口已调用；Q3/Q5 只应消费有效证据，旧历史仍可阅读但不能当作新版验证结果。 |

没有要求集成窗口修改 main.py、TaskService 或前端。Q5 只能把这些字段当作来源和活动定位，不能把 `explained=True`、浏览推进或学生自报理解当作掌握证明。
