# 整套代码集成边界

日期：2026-10-19。当前有效契约，配套 IMPLEMENTATION_PLAN.md 的 Q0—Q6。此前 NATIVE_CONTRACT.md 属于已停止的应用委托路线。

## 目标与集成方式

保留整套能力接入目标及 11 个能力、14 个扩展、100 个工具的覆盖台账。用户允许成组复用、整模块替换和内部架构调整；本契约不把目标缩减为几个工具、提示词或最小试点。

将 DeepTutor 的业务实现迁入、改造成本项目模块，或直接引用可独立使用的固定源码模块。允许采用完整对话循环、完整检索链和整组件；关键在于实现属于本项目的执行与数据流程。

整轮请求不能通过 API 或 SDK 交给另一个完整 DeepTutor 应用组织执行。专用 embedding、模型、沙箱、渲染和语音服务可以保留，其接口承担明确计算任务。

## 主流程与模型

现有 API 和页面继续是入口。TaskService/Orchestrator 内部允许重组、合并或替换；保留业务职责不等于保留旧的全部调用步骤。每轮由一个回答编排者组织，不能旧路由/规划/生成和迁入循环各跑一遍。

迁入循环调用本项目模型入口，统一凭据、预算、超时、图像要求和错误处理。成熟的 Provider/协议实现可以迁入 llm 模块；不再以访问独立 DeepTutor 生成接口作为主链目标。

## 数据与业务权威

| 数据 | 权威与适配 |
| --- | --- |
| 学生、课程与资源权限 | 本项目服务端；迁入代码使用当前账户与课程上下文 |
| 任务、幂等、取消、事件与恢复 | 本项目任务身份和仓库；按需扩展协议字段，不另建上游身份映射体系 |
| 教材、索引、原图与引用 | 本项目发布清单及原文/PDF；迁入节点必须映射到当前来源与版本 |
| 对话与模型协议历史 | 本项目会话数据；适配新协议但不引入第二套原生会话存储 |
| 偏好、摘要、日志与学习接续 | 本项目 memory/database；迁入算法与工具，不迁入另一套账户数据库 |
| 作答、评分与掌握状态 | 本项目统一 attempt/evidence；一个有效事实只写入和推进一次 |

新模式字段应明确区分执行状态与核验状态。未经核验的教材草稿不能作为正式答案或已确认事实回放；不能为了复用流式输出机制跳过原文、图像与引用要求。

## 工具、交互与恢复

工具列表保留全量覆盖，执行时按角色、课程、资源与能力挂载。迁入代码不自动授权联网外发、第三方写入、执行任意命令或跨学生读写。

ask_user 的卡片、答复和继续必须关联本项目原任务及调用身份；刷新和重复答复不启动另一轮无关生成。取消传至实际执行步骤，重放只读已保存事件/结果，无法恢复的执行明确失败而不是悄悄重跑。

删除、遗忘、版本变更和账户清理在上下文构建、调用、保存和恢复时生效，覆盖迁入代码新增的协议、摘要、日志与缓存。代码集成不能弱化已有的删除语义。

## 迁入证据与验收

每批登记来源固定 SHA/文件、许可证及必要 NOTICE、迁入文件、依赖闭包、修改说明、原调用点的保留/合并/替换与实际验证。来源副本保持可校验，业务修改放在本项目。

历史 worker、网关和原生运行时测试只证明当时试验，不自动折算为新路线完成。质量以当前页面的同题多轮表现和原文核对衡量；功能以迁入代码经过真实项目调用点衡量。完成范围仍按完整矩阵逐项核验。
