# Q4 首批教材与学习上下文工具实施计划

日期：2026-10-24；状态：待实施。依据：[首批工具复用调研](Q4_FIRST_WAVE_TOOL_REUSE_AUDIT.md)。编写时main为`9cb5431`；上游DeepTutor固定`6cf793bd868ba5ecbe64722936d4be8fab5a01df`（Apache-2.0）。执行前核对后续提交与实际运行版本。

## 1. 目标与范围

让现有AgentLoop按需查看真实教材结构、读取指定原文、展开已有来源、了解当前学生已记录的基础与偏好，并能请求阅读器定位和盘点公开教材文档。

顺序：**4个只读工具 → 阅读器动作与清单2项 → 联合验收**。已有read_skill补可发现性与实际调用，不重做实现。沿用Q3协议、Q4授权注册表、现有Q2/LightRAG、Q5及记忆库，不全开100工具。

本轮不接web搜索、写记忆/笔记、评分、exec/cron、媒体生成或MCP/CLI provider，不升级工具框架、不建上游ReadingStore/账户/JSON学习库。现有read_skill只提供指导文本，不宣称可视化或执行能力已完成。

## 2. 当前准备与新增缺口

已有：build_registry→ScopedToolRegistry→LocalAgentLoop→tool_dispatch；参数校验、scope、去重、超时返回、ask_user恢复、临时图片和Q2证据发布。原调查74项测试通过不是本计划通过。

尚缺：本轮可信材料/来源/记忆绑定、新工具真实schema挂载、非教材事实回答的发布规则、跨工具全局编号和阅读器动作回执。mounting.py的名称/flags不代表实际入口已启用。load_tools的deferred_loader仍为空，不以其作为本批前置。

新增Q5基线包括9d5f5f6、79becb1、9cb5431的本次安排/恢复/偏好接线；工具须读取同一已确认数据，区分本次约束与长期偏好，不重建同义存储。

## 3. 工具与复用契约

| 工具 | 最小入参 | 可信资源与返回 | 复用来源/原则 |
|---|---|---|---|
| material_outline | 可选chapter_id及有界limit | 当前授权教材的章/节/目标ID、标题、版本、分页/截断信息 | 上游MaterialOutlineTool契约；复用course_navigation.outline与实际章/节清单，不用语义召回猜目录 |
| read_material | 单一locator：已授权文档页码/页范围，或稳定unit_id | 原文及准确范围、SourceRef/Q2 evidence、是否截断；需要图时复用现有媒体链 | 上游ReadMaterialTool的按位置读及限量；复用read_target/pdf_reader/source_mapping，不新建PDF解析器 |
| read_source | 当前source_index中的source_id | 展开真实原文和有界父范围；已有编号复用，新范围重新核验 | 可摘取上游ReadSourceTool查表与错误处理；不能把任意索引文本直接当已核验证据 |
| read_memory | 无学生ID参数；可选白名单section（profile/preferences/recent） | 当前学生、当前课程可见的画像/已确认偏好/必要学习摘要，带已知/缺失与来源类型 | 上游ReadMemoryTool用途；本地MemoryManager/Q5状态为权威，不读上游L3文件 |
| reader_goto | 合法source_id或已绑定document/version/page，quote可选 | 可信导航请求、action_id、requested/applied/rejected状态；未匹配quote不高亮 | 上游ReaderGotoTool/_goto_result的对象与引句检查；接本地阅读器，不写掌握或Q2下一目标 |
| kb_files | 可选公开文档名pattern及limit | total/matched/listed/omitted、公开文档ID和版本；定义统计范围 | 上游KbFilesTool/manifest筛选与报告；不把SQLite、sidecar、325个入图文件当作书或章数 |

工具schema采用现有ToolParameter/raw_parameters；复用当前参数校验，对新工具闭集参数拒绝未知字段。页号必须说明生成阅读版/原教材页号，复用page_map，不由模型猜测。read_material互斥locator只选一种，不能同时页范围与unit_id导致歧义。

建议初始读取预算：最多3个页面或1个目标、总原文最多12000字符；目录单页最多50项，清单默认20/最多100项，记忆摘要最多4000字符。执行前按实际资料验证边界，截断返回可继续定位，不能静默截断后声称全文。

## 4. 上下文、授权与来源

### 4.1 宿主注入

ToolContext.state注入本轮授权课程/文档绑定、source_index与有界只读服务。课程、document/version/release、student/session从TaskService和已核验上下文获取，模型不决定用户身份、服务器文件路径或任意数据库记录。

- scope建议按当前底座声明：course:read、sources:read、memory:read、reader:navigate；实现前复核是否已有同义scope，避免重复名称。
- 有资源才挂载；缺资源返回明确不可用，不回退项目根目录或其他课程。只读工具与reader_goto不获得learning写scope。
- 初始source_index来自本轮合法附件/已核验来源；retrieve_course/read_material成功后追加，不能只初始化一次。限制条数和总大小，ID不可跨任务使用。
- loop_state仅保存可重新核验的身份/指针；恢复时重建服务及授权，不保存数据库session/回调对象。版本变化或学生切换时拒绝旧指针，不把历史内容自动升级。
- 记忆缺失明确返回空，不从聊天语气猜基础；跨课程知识水平不自动通用。删除/epoch后读取最新状态，敏感管理字段不发送模型。

### 4.2 全局引用

read_material/read_source和retrieve_course共用同一来源分配/去重/发布边界，不各自从[1]开始。按版本、块及实际范围去重，同节不同原文保留；扩大读取范围须重新核验，不能复用不覆盖新文字的旧evidence。

图表复用SourceVisual、当前媒体ID、临时模型消息和同图质检；read_material返回图题不等于模型看过像素。元数据/目录/画像不得混入TextbookChunk或编号为教材引文。

## 5. 发布与流式兼容

当前_publish_gate要求教材来源，新工具接入必须补结果分类。最小扩展现有任务结果元数据，区分教材事实回答、目录/清单、个人状态、导航回执；分类由服务端任务与工具结果核定，不能仅信模型一句“这是状态查询”。

- 教材知识解释、引用和图片解读保持原事实/版本/像素门禁。
- 单纯目录/清单/已记录偏好可依据其结构化结果发布，不硬插教材引用；无结果则不能编造。
- 混合“我喜欢什么讲法，并解释自变量”须同时满足个人状态与教材证据，不能借read_memory绕过引用门禁。
- 技能文本不是教材来源，不因为read_skill成功就允许无证据专业断言。
- 与STREAM_RETRACTION_IMPLEMENTATION_PLAN同一输出契约：工具调用过程显示真实进度，不把工具原始JSON当正文；保留answer_id/revision/seq、取消、最终收据及未发布草稿边界。若流式窗口尚未交付，先独立实现工具/服务测试，经稳定提交再接公共循环，避免各自改一套阶段规则。

## 6. 阅读器动作契约

reader_goto是UI导航动作，不是学习状态更新。复用现有阅读器挂载、引用定位及pdf-position路径；不改滚轮手势实现。

1. 服务端校验授权document/version/page及quote，生成task_id/task_revision/action_id/目标位置。无真实矩形仅允许页/小节定位；quote不匹配可到合法页但不能假高亮。
2. 通过现有SSE增加有界reader_action事件（或等价现有动作通道）；不得仅塞ToolResult.metadata而无人消费。参数只允许受控ID/页码/位置，不接受任意URL、路径或脚本。
3. 前端核对任务/当前会话/文档版本和事件去重后执行；取消、过期revision、后台已切换材料或用户正圈选时明确延后/拒绝，不强行夺走当前操作。
4. 实际阅读器完成到达后返回applied回执；失败给rejected原因。优先复用既有task路由/结果元数据，只有无等价入口时新增最薄的鉴权回执入口，不另建消息系统或业务表。
5. 工具初次返回只能说明“已请求跳转”。模型/页面只有得到真实applied才可说“已到达”；没有回执不能宣称成功，不为等待页面死锁整个模型循环。
6. 动作仅本次执行，重连/刷新不重复自动跳页；历史可提供用户主动点击的“查看原文”。保存可核对的最终动作状态，不能让旧任务控制当前阅读器。
