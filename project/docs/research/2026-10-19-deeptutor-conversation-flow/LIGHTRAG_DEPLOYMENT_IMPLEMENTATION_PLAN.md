## 1. 目标与路线

交付固定提交、完整宿主资源、现有 LightRAG 候选与独立依赖可组合运行的版本，保留流式、引用、图表和学习位置。证明不依赖旧 worktree/旧候选目录后，再根据验收范围受控更新本地运行服务。

选用：**现有原生 SDK 接入 + 官方资源分离布局 + DeepTutor 已有版本/生命周期机制**。

| 路线 | 判断 |
|---|---|
| 完成当前原生接入 | 本轮执行。已有图谱、证据映射和真实检索记录，改动最小 |
| DeepTutor HTTP 客户端 + 独立 LightRAG 服务 | 条件备选。仅当原生依赖隔离仍有可重复、无法局部解决的问题时另立批次；先验证结构化来源完整性 |
| 迁入完整 RAG-Anything/Dify 或重建框架 | 本轮不采用；不能直接修复本项目输入域、历史 URI 或验收脚本问题 |

本轮不重建全书图谱或既有 Q2 索引，不迁移学习库结构，不扩展评分/复习/全书规划，不为了切换升级 SDK 或改变 embedding。教材审核与技术部署分别核对，不能以技术通过自动将 pending 改 approved 或 ready=false 改 true。
