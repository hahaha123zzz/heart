# 第四层实施计划：契约与评测基线

日期：2026-10-31。基线：`94ba9ca`。独立分支：`codex/layer4-contract-baseline-20261031`。

本批执行已确认调研建议的第一步：形成第三/四层接口和可复核的教材评测基线。复用SourceRef、ContextHeader、Constraint和现有来源验证；不新增检索框架、不改变公共执行入口或教学策略。后续LangGraph接线另按本批稳定契约实施。

| 阶段 | 本批交付 | 验收 |
| --- | --- | --- |
| E0 | 固定教材输入与代码基线，隔离worktree | 文件hash、禁止覆盖旧产物 |
| E1 | 请求/结果/需求覆盖契约与纯适配辅助 | 缺失、可选、失败、来源串用、JSON恢复测试 |
| E2 | 60个分层评测候选与来源清单 | 对象/原文hash、版本、引用坐标及待审核状态明确 |
| E3 | 本地候选验证与离线结果评分脚本 | 同版本、无重复、缺侧、无结果等真实风险用例 |
| E4 | 定向回归、交接文档和稳定提交 | 不计作正式接线、模型收益或教师审核通过 |

接口按现有身份和来源结构建立：第三层提供每项必须/可选证据需求、对象范围及约束；第四层返回来源、覆盖状态和工具结果。已有EvidenceBundle执行原文/坐标验证，契约只检查形状和相互一致性，不取代真实性与语义验证。

需检查的调用方：未来agent_loop_service/TaskService接线方、CourseSearch输出、EvidenceBundle来源投影、第三层策略输出和离线评测。由于本批接口尚未接公共入口，上述既有调用方不改；新模块只被本批测试/脚本消费。

公共禁改：TaskService、agent_loop_service、AgentLoop、answer_events、公共发布门禁、frontend/app.js、数据库迁移、第三层/六维分类器源码。外部模型与正式学生数据不参与本批。

评测候选必须分开记录：教材来源核验、位置核验、语义参考答案审核、教师批准。图片只绑定原图不冒称看过像素，公式原始OMML不冒称已识别LaTeX；负例显式标记。候选集是诊断/标注输入，未经审核不计算对外宣称的质量达标率。
