## 合同和边界

- KC ID、教材目标 ID、Q5 路径目标 ID 各自保留。Q5 路径通过已有 `source_refs` 的 `unit_id` 和版本匹配当前导航目标，不凭标题合并；目标映射、KC 和来源都需审核且有效。
- 别名查询返回所有同名候选，`related_to` 不作为同义词。先修关系校验悬空、自指与环，不从教材顺序推断先修。合并或拆分不会移动历史掌握状态。
- 评价映射由仓库注册表提供；调用方只能查询已有映射，不能通过请求体声明已审核。指纹覆盖题面、答案、rubric 与完整映射；当前导航版本、注册表版本或来源变化会使映射失效。
- 按 rubric 标准返回被实际评价的 KC 和原始分项结论；单条标准若声称同时评价多个 KC，则该标准不输出覆盖，避免将一份结果复制为多份测量。`partial` 和 `unclear` 原样保留，不转换为二元掌握。
- 当前没有正式评价映射，也没有教师审阅的 KC。单元测试使用的 reviewed 与 reviewer 均为合成夹具，不是实际审核记录。该模块不写数据库、不改变第三层决策或现有课程导航。

## 待课程教师核验

确认候选行为和术语边界；逐项审核教材来源、目标映射和细分 rubric；为真实题面、参考答案及每个可观察标准确认映射后，才能通过受控代码审阅登记实际审核人和对应指纹。后续 PR3 应定义评价机会、修订和事务持久化；不能把本次查询结果直接解释成学生能力更新。

## 实施与验证

在本机课程资料上，来源文件摘要和章/节块号核验通过；候选导航映射返回空的可投影 KC。注册表、适应式教学及教学证据回归共 41 项和 6 个子测试通过，覆盖来源和路径版本变化、题目及评分材料变化、同名歧义、多 KC 标准弃权和先修图校验。课程目标、导航及注册表的另一组回归共 39 项和 29 个子测试通过。合成 reviewed 记录仅用于验证机制。

课程资料属于本机恢复的外部测试数据，不随注册表提交；缺少资料时来源核验失败，不能把映射升级为有效。仅为 `kc_registry.json` 增加 Git 忽略例外，原有课程数据仍保持忽略。
