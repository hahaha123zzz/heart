# 教材图表索引设计

日期：2026-11-04
课程：experimental-psychology-3《实验心理学（第3版）》
状态：设计已确认，进入实施

## 目标

为教材中真实存在的插图和表格建立一份按“章 → 节 → 小节”组织的 Markdown 索引，让回答模型在答题前能先判断当前知识点是否需要引用教材图表；索引负责“选不选”，不负责“讲什么”。

## 已确认的范围

- 收录：有编号的真实图/表、无编号但有实际内容的图、合并后的 Word 数据表。
- 排除：二维码、栏头、装饰条、灰色装饰块、“书版小样文件缺图”占位图、章节教学目标等排版表格。
- 预计规模：约 130 张真实图片 + 约 80 个合并表格，最终以视觉审核结果为准。
- 不修改教材原文件、`assets.json` 审核状态或现有发布清单。

## 现有数据的已知问题

- `assets.json` 的 `labels` 由邻近文本推断，可能错配：已确认 12 张有编号资产实际是二维码/装饰/缺图占位。
- 82 张无编号资产中只有 1 张真实示意图，其余为装饰或占位。
- Word 表格经常被拆成多个 `table` 块，且大量例题表没有表号。
- 现有 `source_visuals` 只按尺寸过滤，仍可能把二维码和缺图占位当教材图返回；新索引必须排除，工具不得返回这些 `asset_id`。

## 产物

路径：`knowledge/course_visual_index.md`，单文件。

结构：

```markdown
# 实验心理学（第3版）图表索引
> course_id: experimental-psychology-3 ｜ 条目: N ｜ 已核对: N ｜ 待核: N ｜ 缺图: N

## 第3章 相关设计和准实验设计

### 第一节 相关设计

#### 图
- 图3-1｜曲线图｜p.41｜耶克斯-多德森定律示意图｜知识点: 曲线相关、最佳唤醒水平、作业效率｜内容: 倒U形曲线，横轴唤醒水平、纵轴工作效率，中等唤醒最高｜用于: 解释曲线相关、说明动机过高的反效果｜asset_id: image-03-0003｜状态: 已核对

#### 表
- 表3-1｜数据表｜p.40｜两类双生子在加州心理问卷各分量表上的相关度及遗传度｜知识点: 双生子研究、遗传度、同卵/异卵｜内容: 10个分量表的MZ/DZ相关与遗传度三列｜用于: 用具体系数说明遗传度估计｜blocks: 18,20｜状态: 已核对
```

字段固定：

- 类型：图（示意图/流程图/装置图/曲线图/柱状图/照片）或表（数据表/对照表/统计结果表）。
- 编号：`图X-Y` / `表X-Y`；无编号用“节名·序号”。
- 页码：PDF 生成页，用于引用。
- 名称：教材原图注/表题，逐字保留；无图注时用“小节标题 + 对象”。
- 知识点：2–5 个，优先教材原词。
- 内容：一句话，图和表都必须写出可判断相关性的细节；表要写行列、单位、关键数值或结论。
- 用于：学生问什么时该引用。
- `asset_id`：仅真实图片有；表格用 `blocks`。
- 状态：`已核对` / `待核` / `缺图`。

## 标注流程

1. **脚本预提取**：从 `document.json`、`assets.json`、`pdf_manifest.json` 生成每章候选文件，包含小节标题、图片路径/尺寸/邻近图注、表格分组/表头/文本、已知装饰尺寸。
2. **子代理视觉标注**：按章并行。每个子代理必须打开候选图片核对，不能只信现有 `labels`；输出本章 Markdown 片段。
3. **合并校验**：脚本拼接、排序、去重；校验每个 `asset_id` 真实存在、无二维码/占位、每章每节覆盖、每个真实图表只出现一次。
4. **抽查**：抽查 10–15 条对照原图和原文；不一致退回重标。
5. **人工确认**：列出 `待核` 和 `缺图`，由教师决定补图或保留文字说明。

## 工具契约

新增 `lookup_figures`：

```text
lookup_figures(query?: string, chapter_id?: int, section_id?: int, limit?: int = 8)
```

- 不传章节时使用当前 `learning_target.chapter_id/section_id`。
- 默认严格只返回当前小节；当前小节无条目时返回“本节无图表索引，不要配图”。
- 查询明确包含“图X-Y/表X-Y”时按编号精确命中，可跨节，这是唯一例外。
- 返回索引行，不返回图片；需要原图时调用现有 `retrieve_course(asset_id=...)`。
- `缺图` 条目不返回 `asset_id`，模型不得声称展示原图。
- 回答协议新增：回答教材知识问题前先调用 `lookup_figures`；图表确实帮助理解才引用，不强行配图，不在正文列索引。

## 验收

- 索引可被脚本解析；11 章、所有节都有标题；条目数、状态统计与生成报告一致。
- 无二维码/装饰/占位 `asset_id`；无重复编号；每个真实图表只出现一次。
- `lookup_figures` 单元测试覆盖：默认当前小节、同章不串节、图号精确命中、无命中不返回别节、`缺图` 无 `asset_id`。
- 至少 10 条人工抽查通过。
- 现有 `retrieve_course` 行为不变；更新因新增工具而受影响的注册表断言。

## 非目标

- 不修复或生成缺失的教材原图。
- 不把索引当作教材审核通过。
- 不把索引全量注入每轮 system prompt。
- 不做向量检索、额外数据库或新的检索服务。
