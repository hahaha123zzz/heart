三条真实模型复验通过，并人工核对场景、教学事实与教材引用。首次失败及中间输出均保留，不代表首次成功率或长期稳定性。

## 方法

旧进程向独立SQLite写入两个合成学生的历史偏好及明确数值设置，每人再写35条无关进度，使关键记录不在短期窗口中。旧进程退出，新进程加载原main，通过原 `/api/chat` 和新session_id调用DeepSeek，最新问题不提示做饭或篮球场景。图解关闭以单独测试记忆；未使用真实学生资料。

本轮自然语言偏好原文通过历史检索使用；不是验证聊天内容被自动提取成独立画像字段。数值偏好通过已有设置接口对应的set_preferences写入。

## 实际修复

1. 原流程先核验教材、后检索长期记忆，核验器因看不到旧偏好而拒绝。现在先检索当前学生相关记忆，再核验；核验输入单独携带明确设置及最多4条有来源的学生历史。
2. 核验器仍只能从教材evidence引用source_ids，不能把历史当教材事实、能力证明或系统指令。新增回归检查记忆ID不可冒充教材证据ID。
3. 新问题明确时，用本轮召回教材主题定位记忆，避免旧目标“反应时法”给35条无关记录加权、挤掉自变量相关偏好；依赖前文的短追问和明确对象仍保留原上下文。
4. 原PDF圈选入口同步传递已检索的记忆给核验器，避免同类先后顺序缺口。
5. 补充心理学核验范围说明，避免对概念解释强制讲完整章，或一边承认满足场景/标注要求一边据同一项判错。人工曾发现模型通过但例子混淆物理属性与被试反应，已补充学科规则并再次复验，未仅凭模型passed宣布成功。

6. 提前记录记忆版本，并在教材核验后检查删除版本；核验期间删除记忆时立即停止，不发布旧记忆解释，也不重新写入对话或后台记忆任务。生成期间删除仍由原有提交检查保护。

最终60项相关回归通过，覆盖教材核验、心理学流程、跨进程记忆、历史召回与删除管理；不代表全仓库测试通过。真实模型三条结果在删除保护修复前生成；最后的删除保护以确定性回归验证，未重复调用模型。
