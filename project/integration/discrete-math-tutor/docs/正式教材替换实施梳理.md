# 正式教材替换实施梳理

## 1. 已确认输入

正式教材为《实验心理学（第3版）》，白学军等编著，中国人民大学出版社。压缩包含前言及正文两个 DOCX，没有 PDF。文件内部标题及前言目录确认本书共11章：实验心理学概论、心理学实验中的变量及其控制、相关设计和准实验设计、被试间设计、被试内设计和混合设计、单被试设计、心理物理学方法、反应时法、注意、记忆、阅读。

DOCX结构初检：正文163个Word表格对象、165个媒体文件、81个OMML公式对象，未发现OLE嵌入对象。对象数量不等于实际教学图表或公式数量，需去重和分类。正文存在引用其他教材目录的段落，不能将其中的章节标题识别为本书导航。书末存在出版社联系方式和资源推广信息，须与教材正文、参考文献分开。

## 2. 迁移原则

- 新教材独立导入和验收，再切换默认课程；旧教材及现有学习记录保留。
- 教材、章节、知识点、习题、来源引用和学习记忆携带课程/教材版本身份；新书第一章不能与旧书第一章共用语义身份。
- 保留阅读、圈选、问答、图解、练习、记忆等通用能力；移除新课程路径上对旧离散数学内容的固定绑定。
- 旧习题成绩、掌握状态、旧聊天引用不自动映射成新教材知识；通用表达偏好可保留，知识记忆按课程隔离。

## 3. 实施顺序与交付

| 阶段 | 必须完成的工作 | 验收产物 |
|---|---|---|
| 1 备份与样章 | 保存数据库和旧教材版本；清点正式文件；选取含表、图、公式、复习题的一章试导入 | 可回退快照、样章质量报告 |
| 2 结构解析 | 识别本书11章、节、三级标题、概念、实验案例、表图说明、公式、复习题及参考文献；排除引用的其他书目录及营销页 | 结构化教材清单、资源关联及解析审计 |
| 3 阅读与定位 | DOCX转换为阅读PDF；核对字体、公式、图片、表格跨页和分页；建立章节、段落及资源坐标 | 全书导航、圈选、跨章定位与高亮可用 |
| 4 教材检索 | 重建结构与语义切片、关键词和向量索引、概念别名、图表公式资源及引用锚点；样章验证后批量处理 | 新书检索索引、样本召回及引用报告 |
| 5 教学与核验 | 改为实验心理学助教；区分概念解释、实验设计、变量控制、结果解释、统计计算；改造意图、充分性及答案检查规则 | 正确回答教材问题，避免套用数学证明或图论条件 |
| 6 练习与记忆 | 清点并导入正式教材复习题；客观题用规则，开放实验设计题用明确评分维度；隔离新旧课程学习事件与掌握记录 | 新教材练习、来源绑定、课程内记忆恢复 |
| 7 按需可视化 | 保留模板/Skill自动生成机制；优先实验流程、变量与控制对照、被试分组/条件顺序、设计矩阵、反应时或心理物理数据解释；明确示例与真实数据 | 少量代表场景按下一步推进，非每题预生成 |
| 8 验收与切换 | 先样章，再全书；真实问答检查概念、实验案例、图、表、公式、复习题、跨章追问、引用与历史恢复；验证无旧教材串入 | 验收报告、正式课程切换、回退说明 |

## 4. 已发现的代码绑定

- `knowledge/course.py`：旧10章标题及固定章节遍历，旧演示测验。
- `knowledge/pdf_reader.py`：文档ID只接受 chapter-01 到 chapter-10；旧PDF清单、节定位与版本绑定。
- `knowledge/textbook_text/`、结构化检索库、向量/关键词索引、公式与图片清单、`knowledge/pdf_sections.json`：均须针对新书重建。
- `visualization/textbook_guides.py`：旧例4.6、定义9.5/9.6、定理7.11等固定教材出处。
- `agents/task_execution.py`：关系、闭包、真值表与图论特定检索说明。
- 回答生成、意图路由、证明检查、练习判分、教学策略及知识点记忆：检查并移除新课程路径上的离散数学假设。
- 浏览器引用、课程名称及测试夹具：适配新教材身份、11章导航与新知识范围。数学专题组件不作为实验心理学的默认入口。

## 5. 需要明确的条件

- 若甲方提供同版正式PDF，优先将其用于阅读及引用定位；否则需从DOCX生成并固定版面。生成PDF的页号不能未经核对就称为印刷教材页码。
- 练习是否有正式答案或教师用书，影响规则评分和开放题评分依据；没有答案时不能将模型生成答案标成官方答案。
- 本轮只做输入及项目影响评估，没有替换线上教材、修改已有学习记录或完成全书解析。现存关系闭包检索不稳定属于旧课程问题，不能将其作为新课程验收项。

## 6. 推荐第一步

先完成备份与教材身份隔离设计，再选一章验证“DOCX解析→阅读PDF→图表公式关联→检索→问答引用→一道交互练习”。样章通过后按同一流程导入全书，最后切换平台默认课程。当前不宜直接覆盖旧知识库或把全部章节一次性送入模型。
