## 数学及系统验证

- 使用实际嵌套集合检验集合判断，并给出“属于不能推出包含”的反例。
- 穷举三元素上的全部 512 个关系及其子集，验证传递、序、全序、良序的限制性质。有限枚举作为实现检查；一般情形的数学推导另存审核记录，没有用有限枚举冒充无限集合的证明。
- 用具体人口集合核对包含排斥，用组合枚举和骰子枚举核对计数。
- 构造九结点环加三条端点不同的弦，验证 12 条边、6 个三度结点和可达到的最小结点数。
- 检查题面没有缺失图片公式、数值填空数量与控件一致、全部新映射指纹有效。
- 实际 worker 完成新增六组题的批改和技能记忆写入；规则题 AI 调用被测试主动禁止。
- API 验证旧版本 409、缺少填空 422、表达式等价判分、重复提交幂等、答案不在初始题面泄露，以及内部删除版本不出现在公开评分中。
- 错误、辅助作答、学生隔离和全知识点掌握估计保留也已验证。

专项首次组合运行 24 项通过；补充实际 API 验收后新增专项共 10 项通过。完整记忆回归 143 项全部通过（58.141 秒），结果见 [regression.log](artifacts/memory-phase10/regression.log)。

验证使用临时 SQLite 和模拟模型，未调用真实模型 API、未加载 GPU 模型、未修改用户数据库或重启原服务。本轮没有修改 UI，使用实际 API 验证既有控件契约，没有重新进行浏览器展示验收。

## 使用方式

重启应用、重新加载“测验练习”后，可在第 1、3、7、9 章完成表中的习题。数字填空支持有限有理数表达式，例如握手数填 50*49/2；只填文字解释会保守返回无法确定，不据此判错。

完成独立作答后，在记忆管理中查看对应知识点的技能记录，再围绕该知识点提问。当前教学接线使这些记录进入教学建议和模型输入，但不保证真实模型一定遵循建议。

## 范围和后续

技能估计仍未校准，不是全章掌握度；得到提示后的答案不计为独立测量；错误方向仍需诊断，不自动确认误区。

本轮修改全局题库/映射版本。旧草稿、成绩和技能观测保留原记录，但当前版本筛选不会使用旧观测生成技能摘要；没有历史回填或跨版本迁移。原有聊天、画像及其他学习记忆不因此删除。

暂缓多正确选项但仍为单选的题、题意条件冲突的题、符号表达式题，以及需要核对自环定义的生成树判断题。下一步适合完善符号/结构化答案的核验能力，并在确认题意后逐批审核；不直接以 AI 评分替代可靠规则。
