# 第十阶段设计：扩大规则题与技能记忆覆盖

延续第九阶段已批准的服务器规则核验、版本绑定和技能派生方案。新增 22 小题：集合真假 10 项、关系限制真假 4 项、包含排斥数值 3 项、组合/奇偶计数数值 3 项、度数下界 1 项、上下确界 1 项；总覆盖 39 小题、13 技能。

复用 judgement 与 numeric_fill 判分器及现有交互控件，仅增加审核答案、解释与映射。与引入模型自动标注、为证明题建立新评分系统相比，本轮采用可确定核验的数据扩充，便于控制记忆证据质量。

保存新增规则的来源、推导、题面/规则指纹及暂缓题目的原因。用独立枚举或数学构造核对答案，验证真实 worker 接线、部分正确、无帮助要求、学生隔离和题库版本变化；只使用临时数据库与模拟模型。

技能估计仍未校准，不改变全章掌握度、不自动确认误区、不回填旧版提交。新增映射改变全局映射/题库版本，旧技能观测保留，但不会进入当前版本摘要；应用需重启并重新加载练习题库。
