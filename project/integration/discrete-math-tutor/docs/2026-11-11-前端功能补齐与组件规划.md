# 前端功能补齐与组件规划

日期：2026-11-11　状态：已确认范围 P0+P1（P1 收窄，见 §5）

## 0. 结论先行

1. **不换前端框架，不套用参考站的视觉皮肤。** 现有页面是原生 JS + 一套 slate/白灰 token，成本最低、风格最稳的路线是继续用它。
2. 缺口分三类处理：
   - **宿主自建 UI**：后端已有接口、上游没有对应界面（档案、证据、误区、教案、搜索、健康状态、复习队列）。
   - **打开已有原生页**：上游已写好但被桥挡住（掌握路径编辑、记忆工作台深度操作）。
   - **明确不做**：面向管理员/多用户的整页（知识库、笔记本、任务看板、MCP/CLI、语音、多用户）。
3. 导航从 4 个目的地扩到 5 个：学习 / 练习与复习 / 学习记录 / **学习者** / 设置。子功能用标签页承载，不新增更多一级入口。
4. 新增的基础件只有 8 个（tabs、badge、timeline、drawer、accordion、search overlay、status dot、skeleton），全部复用现有 token；**不新增"卡片盒子"风格**。

## 2. 设计锚点（风格合同）

来源以当前 `workspace.css:2` 的 token 为准（不是 10 月截图里的蓝色）。

| 项 | 值 |
|---|---|
| 表面 | `--surface #fff`、`--sidebar #f4f5f4`、`--paper-backdrop #eeeeec` |
| 文字 | `--text #282d31`、`--muted #687176` |
| 线与选中 | `--line #e3e7e7`、`--selected #e6edf2` |
| 动作色 | `--accent #526f87`（只用于主按钮、链接、选中） |
| 状态色 | 绿 `#287868/#e8f4ef`、暖 `#ba4f46/#fbf7f0`、蓝 `#42688b` |
| 字号 | h1 24 / h2 17 / 正文 13–15 / meta 10–12；正文行高 1.9 |
| 圆角 | 控件 5–9、交互件 12、标签 14–999 |
| 阴影 | 仅浮层（菜单、toast、popover） |
| 动效 | ≤180ms ease-out，无 idle 动画，沿用 `prefers-reduced-motion` |

组合规则：

1. **分区不用盒子**：`h2` + 发丝线 + `--sidebar` 底色块。现有 `.card` 已被刻意压平，不要复活。
2. **只有交互件才包边框**：12px 圆角 + `#d6dfe6`，沿用 `.interactive-graph` 的语法。
3. **行优先于卡**：列表项复用 `.review-item` 的结构（主文 + muted meta + 右侧动作）。
4. **状态只给颜色不给装饰**：`.badge` 三档（good/warn/muted）。
5. **一页一个主动作**：主按钮只有一个，其余 `.secondary-button`。

参考库取舍：

| 参考 | 取什么 | 放在哪 |
|---|---|---|
| Solid Glass | Agent 状态/工具步骤/审批卡的**信息结构** | 复习动作确认、记忆写入确认、升级现有 `.turn-progress` |
| AffectUI | trace / tree 的**时间线语法** | 学习证据、能力目录 |
| BoardUI | 仪表盘的**密度与对齐纪律** | 学习记录概览 |
| Looseleaf / Inkra | 只取"纸感"插画/空状态，最多两处 | 教案抽屉、首次空状态（可选） |
| PlopUI / goopUI | 不取 | 与冷静的数学阅读语气冲突 |
| Prestige UI / motion-prompt | 不取 | 付费落地页组件 / 无对应语义 |

## 3. 信息架构

```
学习 ───────── 教材正文 + 对话        [+ 侧栏搜索浮层] [+ 章节小测(P1)]
练习与复习 ─── 原生题库/错题/到期练习   [+ 顶部"待复习 n"条]
学习记录 ───── [概览] [掌握路径(原生)] [复习建议]
学习者(新) ─── 画像 · 掌握明细(展开=误区+教案+证据) · 证据时间线
设置 ───────── [偏好] [学习记忆] [系统状态] [测试账户]
```

- 对话面板只在「设置」页隐藏（`workspace-layout.css:85-86`），其余页面保留；对话列表只在「学习」页显示。
- 「学习者」入口复用已设计但未接线的底部标签（`index.html:27` 的 `.learner-label` → 改成 `nav-item`）。

## 4. 组件与组合

新增基础件（都写在 `workspace.css`/`native-ui.css`，约 300 行）：

| 件 | 用法 | 复用来源 |
|---|---|---|
| `.tab-strip` | 页内子视图切换，等宽文字标签 + 底部 2px 选中线 | `.part-navigation` |
| `.badge` | 三档状态 | `.demo-badge` |
| `.timeline` | 证据/运行记录，左侧 1px 线 + 点 | `.turn-progress` |
| `.drawer` | 右侧详情（教案、证据详情），宽 420px，Esc 关闭 | `.sidebar-library` 浮层 |
| `.accordion` | 掌握明细逐行展开，懒加载子资源 | `.review-item` + `<details>` |
| `.search-overlay` | 侧栏搜索，键盘上下 + Enter | 新增（唯一真正新增的交互） |
| `.status-dot` | 引擎/worker 健康 | 现有绿/暖色 |
| `.skeleton` | 原生面板加载占位 | `.resource-note` |

页面骨架固定为：

```
PageHeader（kicker + h1 + 副标题 + 右侧动作）
TabStrip（可选）
Section[]：h2 + meta + 内容 / 空状态 / 行内错误
```

状态规范：加载=骨架或 `正在读取…`；空=`resource-note`；错误=行内 `role=alert` + 重试；部分失败只降级该分区，不整页报错。

### P1　需要桥或原生改动

| 能力 | 去处 | 做法 | 量 | 风险 |
|---|---|---|---|---|
| 记忆条目管理 | 设置-学习记忆 | 宿主代理加 `entries` 动作（引擎 `lines`），条目列表 + 逐条删除；去重/审计运行留到 P2 | 1d | 无 SSE，读多写少 |

**P1 不收窄的部分（本轮不做，单独立项）**：建路径、改知识地图、会话模式、从书/笔记生成路径。原因：`topics`/`map` 的载荷是多层嵌套模块结构，上游 UI 已经实现但走 `api.ts` 全量映射 + 原生 bundle 重建，代价与风险都高；先用上游页面路线单独评估。

### P2　暂不做（写进说明，避免反复讨论）

| 项 | 理由 |
|---|---|
| 知识库 / 笔记本 / 课程库整页 | 上游 33 个文件/9k 行，需 multipart + SSE 索引 + `useParams` 补齐；单教材场景收益低 |
| 任务看板 / 会话回收站 / 多用户 / 守卫 | 面向多用户后台，与"一个学习者一个教材"不符 |
| MCP / CLI apps / 语音 / 模型供应商设置 | 管理员向，暴露给学习者只会增加误操作 |
| 单题 help REST | SSE 版本已覆盖，保留作为离线重试即可 |
| 图数据库浏览器 + 心理教材预览 | 两个独立服务未挂主应用；要么挂 `/static` 链接，要么删，单独决定 |
| 死代码清理 | `submitQuiz`、`assessment_api.py`、`graph_viewer.py` 建议单独一次清理提交，不混在 UI 改动里 |

## 6. 实施顺序与验收

1. 前置验证（0.5d）：真实调用一次复习动作，确认不是 503；确认原生主题改动的截图基线。
2. 基础件 + 学习者页（2.5d）。
3. 学习记录三标签 + 复习队列（1.5d）。
4. 设置四标签 + 系统状态 + 测试账户（1d）。
5. 搜索浮层（1d）。
6. P1 按确认结果排期。

验收：桌面 1600×1000 与手机 390×844 各一轮；沿用 `scripts/check_native_*.cjs` 的注入式浏览器检查；新增交互至少一个 assert 自检（搜索无结果、证据空、复习按钮禁用/恢复）。

## 7. 已定的三个决策

1. 「学习者」做独立页（复用底部已有的入口位置），不塞进学习记录。
2. 正式复习队列放「学习记录-复习建议」标签；动作本身会跳回对话。
3. 掌握路径本轮只做 4 个简单写动作；建路径/改地图另立项。
