# 教材 RAG 原 PDF 证据补全（2026-10-11）

## 问题与根因

上一轮的有序对与笛卡尔积分量问题已召回正确小节，但正文缺失公式，且未带入下一页的说明；充分性核验因此暂停讲解。核对原 PDF 第 11–12 页，定义、相等判定、与无序集合的比较均真实存在。Word 提取正文与原页之间存在信息丢失。

## 实现

新增 knowledge/pdf_evidence.py，在现有混合召回完成之后补充证据，不改变排序、相关性门槛或充分性核验规则。

1. 对带公式资源、公式类型或公式占位符的已召回片段启用补全。
2. 核对章节文件名、已验证小节 ID 与标题；限定在小节页码范围搜索。
3. 优先按定义、定理、例的完整编号定位，备用为原文中的连续中文短语。有编号却找不到时不降级为模糊匹配。公式前后背景中的编号不能冒充该公式的锚点。
4. 从锚点开始，最多读取相邻两页并在下一小节之前截止。复用现有 PDFSelection 与 resolve_selection，核验教材 SHA256、页码、坐标与裁图完整性。
5. 将原 PDF 文本及两张原页裁图同步提供给充分性检查、回答生成和生成后质检。字体编码导致文字层含特殊字符时，模型以清晰原图核对公式，不由程序猜测补写。
6. 返回原页图片及可点击的教材位置，保存在助教消息引用中；标记 origin=retrieval，与用户自己圈选区分。
7. 精确定位失败、教材版本不一致时保留原证据，由充分性门槛决定是否能回答。依据不足的响应不显示原页图片或教材引用。

本轮不重新训练模型，也没有重建向量索引。改善的是召回之后的证据完整性。

## 检索输入的第二个问题

首次完整接口复测发现，路由可将明确的数学基础问题判为图论的相关追问，随后拼入旧知识点，导致召回图论片段。原页补全只能补充已召回的位置，无法纠正召回位置错误。

现将“是否切换学习目标”与“检索是否需要前文”分开，路由增加 needs_context 布尔字段。完整的独立问句优先使用原问句；指代性追问和学生作答保留当前知识点。测试覆盖字段异常、独立问句、指代追问和学生作答，未增加关键词黑名单或调低门槛。

## 验证

- 59 项单元及检索回归测试通过，包含原式恢复、相邻页说明、错误小节、未知编号、背景编号、完整表格与版本异常保护。
- 检查了原页与生成裁图，确认有序对定义及下一页说明可读。
- 真实模型对同一原 PDF 证据的四个诊断问题：有序对与分量问题均 sufficient；订单数据库与 JavaScript 问题均 insufficient。属于已知问题的诊断回归，不是独立基准准确率。
- 正向两题核验耗时约 2.9–3.2 秒；负向约 1.4–1.7 秒。仅是一次小样本实测，受网络与视觉 API 成本影响。

原始结果位于 artifacts/pdf-evidence-real-api.json；首次及第二次结果另存 first、second 文件，不覆盖诊断历史。临时测试账户均通过 DELETE 接口删除成功。

裁图视觉检查发现相邻正文页还包含练习，已按 PDF 行坐标在独立的“练习/习题”标题前截止，正文仍保持原样。该保护通过回归测试。首次截断后的真实接口测试虽通过模型质检，却转入诊断选择题，且选项有不止一个正确项，人工审阅未视为验收通过。原始结果保存在 pdf-evidence-proof-clean-before.json。修复显式解释请求的动作优先级后再次复测：HTTP 200，sufficient，生成后质检通过，question_spec=null，直接给出任取 x∈A、推出 x∈B、再推出 x∈C 的证明；无诊断选择题，未推进步骤。两张裁图均 HTTP 200，返回正文不包含练习标题。整轮耗时 18.57 秒。结果另存 pdf-evidence-proof-clean.json。

## 另外两处衔接修复

- 根据教材定义1.3的实际用词，将 ⊆ 关联到“子集合、子集、包含于、包含关系”。只扩展检索术语，不宣称不同符号等价，不改学生原问句。集合符号问题召回带编号的定义/定理时，也可核对原 PDF，解决 Word 文本将包含符号漏成 AB 的问题。
- 直接回答问题时的教学计划统一依据 move.action=explain，而不只检查 direct_explanation 标签。概念对比也可执行 explain，应避免继续附加诊断选择题并导致质检冲突。用户明确要求解释、说明、为什么、为何或讲解时，同样优先解释并跳过诊断题设计。学生作答路径仍保留原计划。

## 边界

- 每轮最多补充一个来源、两页，不能保证跨越更多页的证明完整。
- 无可靠小节映射或正文锚点时不补充；这仍需优化原始解析与定位。
- 最简定义证明题的模型误拒问题尚不能据此宣称全部解决；需区分教材证据缺失与核验器判断错误。
- 不能保证所有图片、公式和表格均已修复，也不能用四个诊断问题推断总体准确率。
- 生成后质检可能漏掉诊断题的多正确选项，不能把模型自评 passed 当成答案正确的证明。诊断题的选项校验还需单独加强；本轮显式解释请求跳过诊断题流程。
