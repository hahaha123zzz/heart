# PDF 文字选区接入统一教学循环

用户选择第一种方案并授权实施：统一 AgentLoop，保留不同入口的取证方式。本轮交付文字划选；区域图片、作业题、专用互动图不在本轮替换。

新增服务端选区适配层，使用既有 resolve_selection 核验版本、文件哈希、页码、坐标并读取实际文字；浏览器预览文字不作为证据。选区原文为固定主证据，按几何距离补充同页同小节附近段落，最多四条、每条有真实坐标。不调用全书语义检索替换选区，不能因短词选区被模型选成章节标题而丢失目标。

适配层提供锁定 LearningTarget、已核验 SourceRef、受限补读工具和选区教学指令；生成、teaching_step、待答评估、发布、SSE、保存仍走现有 run_agent_loop_turn。引用继续经 EvidenceBundle 和质量检查。新题绑定选区身份（文档版本、坐标哈希），不同选区不能继承原题。明确仅提示约束传入生成与质检。

真实模型验收发现旧选区对话会干扰新选区解释：切换身份时只清空本轮模型输入里的旧对话，不删除页面历史；同一选区仍保留对话。发布检查拒绝在已有服务端正文时声称没有收到选区，允许诚实说明某个新事实缺少依据。

选区附带状态与既有 TaskContext 一起保存。重复发送同一选区时先识别作答/困难/恢复，不重新开始解释；刷新后无 selection 的明确追问或待答答案，可从同学生/会话/epoch 的最近成功任务恢复坐标并重新验证。新章节、小节、明确新主题和其他对象不恢复旧选区；失败回合不覆盖已提交状态。选区讨论不推进 Q5 正式路径或已确认活动。

用 SELECTED_TEXT_AGENT_LOOP_ENABLED 开关隔离，可回退旧选区流程。保留现有 1800 秒任务有效期，不增加新数据库。图片裁片仍保留页面预览，但文字模式不宣称模型已看见像素；图片区域继续旧入口。

验收：源码单元测试验证伪造预览、原文/坐标/引用、硬检索边界、选区换绑、待答与插问、失败/删除/跨用户隔离、仅提示、Q5 不推进、功能关闭回退。真实 DeepSeek + HTTP/SSE 验证划选→换例子→原题答案反馈→刷新/重启恢复→换选区；普通教学与旧区域流程回归。先独立数据库验收，再备份并重启本机8000服务。不推送 GitHub。
