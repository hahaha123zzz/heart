# 自适应教学闭环

本设计依据用户已确认的方案实施，不重新要求设计批准。

目标：学生表达困难后，助教结合当前学习对象和先前讲解调整教学；小步检查的后续作答得到具体反馈，而不是重新检索并复述定义。

复用来源：固定 DeepTutor 的 learning/models.py、learning/policy.py 和 mastery 提示词中的学生画像、学习阶段、先教后测、质性检查与反馈语义。保留本项目 TaskService、AgentLoop、学生数据、原文核验和发布职责；不启动另一套完整应用。

实现（2026-10-24 修订）：原先仅参考语义的规则模块改为实际迁入 DeepTutor 纯学习引擎。教学状态随现有任务 context 持久化，复用任务的学生/会话隔离、epoch、幂等和删除边界。状态记录 LearnerProfile、已用教法、PendingQuestion 和辅助练习证据；使用原版 learning_stage/next_objective，不按困难次数机械升级，不产生正式成绩。任务重放不重复更新状态。

教学工具仅记录当轮建议和小步问题，不直接写数据库。讲解和问题通过现有发布门禁后才由任务统一保存。学生明确先讲不考时不出题；跳过检查不记作答错误。存在必要前置知识时拆小步骤；持续困难改变表示方式，不重复同一段定义。

证据：只为同一会话的教学追问复用上一条已完成任务的来源，重新核验课程、原文版本和记忆 epoch；切换对象、删除、过期或图像请求不复用失效证据。新专业事实仍需原文支撑。类比和虚构情境必须标为教学示例，不能捏造观测结果。纯教学安排使用受限的服务端文本，不以任意模型输出绕过事实核验。

验证：纯策略/工具/持久化测试覆盖连续困难、待答作答、偏好、跳过、对象切换、跨会话、失效来源与幂等。原有 AgentLoop/检索/Q5 回归继续通过。隔离服务实际调用 DeepSeek 进行“概念→不会→仍不会→小步作答→反馈→先讲不考”，检查 SSE、状态、引用与刷新；通过后切换当前本地页面并通知用户测试。
