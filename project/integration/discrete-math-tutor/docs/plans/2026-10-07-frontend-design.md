# 离散数学助教前端设计

依据：用户提供的页面参考图确定布局；《实验心理学课程智能体平台.docx》的八项功能确定功能边界，但教学领域沿用现有离散数学后端。

方案：FastAPI 同源提供静态 HTML/CSS/JS。一个启动入口、无前端构建依赖。`main.py` 只挂载页面和 API；课程、测验、学习统计和偏好放入独立 `web_api.py`，复用原来的 Agent、MemoryManager 与 SQLAlchemy，不新增第二套对话状态。

页面：顶栏搜索、左侧导航、课程章节树、教材内容区、助教对话区；测验、个人统计、我的学习和设置作为独立视图。移动端折叠成单列。后端错误要明确提示，不展示伪造数据。

数据流：章节与正文从现有十章教材文本读取；问答调用 `/api/chat`，展示回复及教材出处；测验题由本地题库提供，提交后服务器评分并记录尝试；个人统计从测验记录、资源浏览和现有知识状态汇总；偏好保存到已有 `LearnerProfile.preferences`，并进入回复提示词；难点复习从已有误解及知识状态生成。

资源边界：现有数据只有教材文字，没有课件文件，也没有可直接关联的教材插图索引。UI 显示“尚未提供”，不以示意图冒充教材原图。图片关联 API 为后续补录资源预留。教师端全班统计因缺少认证，按用户要求暂不开放。

验证：离线 API 测试覆盖章节、测验评分和隔离、个人统计、偏好、复习；浏览器检查桌面与窄屏布局、聊天失败提示与键盘操作。真实 DeepSeek 教学质量需用户密钥与人工体验验证。
