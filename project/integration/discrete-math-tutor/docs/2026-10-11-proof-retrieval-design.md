# 长证明检索与前置知识关联
日期：2026-10-11
## 已确认方案
保持混合召回、GPU reranker、证据充分性检查及现有界面。新增经 PDF 版本校验的编号知识单元，保留正文范围、页码、坐标和显式引用关系。只扩展已召回且编号、小节、来源吻合的证明。
## 实现边界
单元终点取下一个编号知识单元、小节或练习标题；重复编号的评述、证毕行不作为新起点。教材省略证明保留标记。显式引用仅关联教材顺序在前的有效单元，自引用和无法解析的引用记录为缺口，不能充当前提。
完整正文进入证据核验；指定蕴含方向或正文片段时优先取相应段落所在页，最多两张原页裁图；前置单元提供独立引用及真实页码。完整证明请求先给路线再逐步解释，讲解不推进学生掌握记录。
## 验证
先固定原文页码与关键内容，再检查单元边界、跨小节关系、错误编号、版本变化、教材省略及端到端引用。评测为开发诊断，不能作为整体准确率。GPU 冷启动独立诊断，当前阶段不反复重启。
