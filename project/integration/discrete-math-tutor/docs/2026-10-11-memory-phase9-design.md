# 第九阶段：规则题技能映射与教学反馈

## 设计

当前题库 341 题、788 小题；17 小题有现成规则答案。采用服务器人工维护的版本化映射，覆盖这 17 小题；暂不自动生成其余题目的技能及误区标签。

每个映射绑定题号、小题、题面与答案规则 SHA256，并保存稳定 skill_id、名称、概念说明、潜在诊断方向。练习来源仍按现有 question.knowledge_point 删除和隔离；技能标签不冒充教材章节掌握度。

新增技能观察表，关联学生、原始练习事件、提交版本、小题及映射版本。重新执行现有规则判分核对反馈。无帮助且规则确定正确/错误/部分正确的作答才可用于技能估计；解析失败、AI 评分、旧版本或未映射小题不作能力测量。

按不同题号/小题取最新有效观测，重复提交同一小题不会增加独立测量数量。暂用初值 0.5、alpha=0.4 的 EMA，明示未校准；不改全章 mastery 或现有课程步骤，不自动确认误区。错误只产生待复习技能及未证实诊断方向。

技能摘要接入统一 MemoryContext 字符预算、学生状态的派生技能字段、TeachingPolicy 建议及记忆管理详情。删除知识点和学生时清理观察；与练习成绩、证据写入处于同一短事务。无历史回填。

## 选择

相比模型自动映射，人工小范围规则映射易核验；相比直接升级全章掌握度，技能观察保留更准确的测量范围。未来新增映射先审核题面和判分能力，再扩大覆盖。

## 验收

检查 17 小题映射覆盖、版本/题面失效、实际规则结果、辅助/未知作答阻断、重复提交与独立小题计数、学生隔离、事务回滚、删除后的晚到结果，以及真实教学规划/模型输入接线。只使用临时数据库和模拟模型。
