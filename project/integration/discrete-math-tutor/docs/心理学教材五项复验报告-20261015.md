## 模型超时

当前相同代理、密钥和模型配置下，项目原参数的最小生成请求约0.8秒正常返回OK，随后真实教学调用正常完成。没有更换模型、绕过代理或用模拟回答代替。此前超时根因仍未确定，不能声称永久修复；诊断记录见 `artifacts/model-connection-diagnosis-20261015.json`。

## 本轮暴露并修复的问题

1. 心理学首轮召回6条，旧补检索上限也为6，导致缺失依据无法补入。心理学现在保留至多3条缺失依据补召回，总量最多9条；旧调用默认上限仍为6，引用顺序及去重不变。
2. 一些父标题切片缺少下级正文。按标题层级补齐子内容，直到同级/上级标题或小节边界，仍有长度边界；不跨章节拼接。
3. 短追问只检索宽泛课程目标。现在仅在needs_context=true时使用最近对话辅助定位，历史仍不能作为教材事实依据，明确新问题不混入旧话题。
4. 准确性要求被误判为仅提示。补充意图识别范围说明，“没听懂”也不自动变成hint_only；简化讲解不擅自转向助教末尾检查题。
5. 比较问题被默认200字截断，导致已召回的控制方法没有展示。比较任务生成预算、截断长度及规则质检同步扩展；真正仅提示任务维持原限制，未关闭教材核验。

## 自动图解边界

变量关系图与随机区组流程/矩阵已通过生成和内容核验。设计比较题的候选图解没有通过核验，系统保留文字、不发布候选图。不能将该题描述为图解验收通过。

图解来源目前可能定位到支持片段或小节标题，不保证每一帧都对应教材中精确的一句。整个全书及所有模板组合没有穷举验收。

## 尚未覆盖

连续追问验证的是同会话历史与偏好使用；未验证重启、跨会话长期记忆抽取和保持。未覆盖全部统计计算、全部纯图片问题、长时间稳定性和多人并发。后续适合小范围试用收集具体问题，不能将本轮结果当成全书准确率。
