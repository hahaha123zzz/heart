# 离散数学学习平台 UI 调研与调整建议

日期：2026-10-09

## 结论与范围

建议采用“学习工作台”：教材或习题占据主区域，AI 助教常驻侧边，目录可折叠，阅读、提问、练习、复习围绕同一个章节上下文衔接。

本轮输出为调研与设计建议。研究依据为用户提供的截图、当前前端代码、公开 GitHub 仓库及官方文档；没有运行这些开源项目，也没有采集当前平台的新版浏览器截图。因此这里是流程与结构评审，不能作为最新页面的视觉验收。没有修改应用代码。

## 原始文档的定位

《实验心理学课程智能体平台.docx》是八项功能的分阶段清单，没有界面稿。可用于离散数学的通用能力包括课程资源与测验、学习数据、带教材引用的问答、图文答疑、分步辅导、难点跟踪、交互偏好、学习适配。当前先服务离散数学学生，教师分析视图可另行规划。

## 当前流程评审

| 步骤 | 判断 | 依据与建议 |
| --- | --- | --- |
| 进入学习 | 信息层级需要调整 | 首页大横幅、目录、教材、聊天并列；把首页改为继续学习与复习入口，学习工作台提供专注空间 |
| 找到章节并阅读 | 需要更大的教材视区 | 用户截图中目录与导航占据较多宽度；目录使用可折叠抽屉，正文占据主要宽度 |
| 圈选后提问 | 已有功能，连续性不足 | frontend/app.js 的 askPDFSelection 在课程页调用 showView('chat')；改为保持阅读位置、在侧边展示选区并提问 |
| 转到练习 | 已有章节衔接，应增强位置保持 | startPractice 使用当前章节或 AI 选区章节；增加返回教材时恢复页码、缩放、选区和练习位置的明确验收 |
| 作答和看反馈 | 功能完整，长题阅读负担较大 | frontend/practice.js 的 renderQuestion 使用 q.parts.map 展开所有小题；建议默认聚焦当前小题，允许查看整题 |
| 复习和看记录 | 入口可合并，状态需准确 | 合并重复学习记录入口；阅读完成、提交、规则判分、AI 辅助结果应分别表达 |

## 三种路线

| 路线 | 优点 | 代价 |
| --- | --- | --- |
| A：学习工作台（推荐） | 教材、助教、练习连续衔接；适合公式和图的阅读 | 需要整理页面结构和共享状态 |
| B：对话为主 | 适合 AI 带领逐步学习 | 查阅长教材和来回核对图表需要额外设计 |
| C：保留结构，调整样式 | 改动较少、可快速改善密度 | 页面重复与阅读中断仍需要后续解决 |

## 推荐设计

### 导航与首页

主导航建议为“学习首页、课程学习、练习与复习、我的学习”；偏好设置放到用户菜单。独立答疑可作为快捷入口，章节学习时直接用工作台助教。首页优先显示继续学习、未完成练习、待复习内容，弱化大幅宣传横幅。

### 学习工作台

顶部为课程、章节、学习模式与页码。目录抽屉宽约 220–260px，可关闭；主区域教材约占可用宽度 60%–70%，助教宽约 360–420px，支持调整。具体尺寸需在界面预览中验证。窄屏使用“教材 / 助教”切换，并保留选区和阅读位置。

教材圈选后出现“向 AI 提问”，侧边显示文字或截图预览及章节页码。可选择“解释、逐步提示、举例、检查理解”，再编辑问题发送。选区与当前章节构成主要上下文，相关学习记录按问题检索，并允许展开查看其依据。

助教展示真实后端阶段，例如检索教材、查找相关学习记录、生成回答；耗时、失败和重试明确可见。回答包含教材引用、公式与图片，引用回到原页与选区。分步讲解是学生可用的教学内容，不把内部推理当作进度展示。

### 练习与复习

保留已有公式、图、矩阵、选择与填空组件。默认聚焦一个小题，保留共享题干、整题查看和题目导航。保存草稿、提交批改、提示、AI 讲解位置一致；反馈区区分规则结果与 AI 辅助结果，后者保留待确认标识。

完成阅读或引导学习后，以明确按钮进入相关练习。练习支持返回教材并恢复位置。复习列表按知识点关联教材、错题与待确认难点；仅阅读过或得到 AI 评分不能直接标为“已掌握”。

### 视觉方向

采用白色与浅灰底、单一蓝色强调、较少卡片嵌套。教材与题干使用清晰的阅读排版，工具栏更紧凑。紫色仅作为少量 AI 状态辅助色；减少重复标题、装饰图和过多状态徽标。

## 技术改造顺序与验收

1. 先制作学习工作台界面预览，确认正文与助教的空间分配、导航和圈选操作。
2. 整理统一学习上下文：章节、节、页码、缩放、选区、当前练习及对话。保留现有 React PDF 阅读器与后端 API。
3. 接通侧边助教、引用跳转、练习切换及返回阅读；每一步保持学习位置。
4. 再调整首页与学习记录，加入准确的复习状态。

重点验收：跨章目录确实改变 PDF 页面；圈选提问不离开教材；图片和公式引用可返回位置；练习草稿不因页面切换丢失；批改中途退出可恢复结果；错误可重试；小屏能完成阅读与提问。

相关记忆的可查看与纠正、学习掌握估计等若缺少后端能力，需要补充接口与数据规则，不能仅由 UI 生成状态。使用开源组件前再核对接口适配和许可证；当前阶段借鉴交互设计即可。
