# 第十一阶段：受限符号填空核验

延续规则核验及技能记忆方案，复用 SymPy 1.14.0 的有理数与 Poly 运算。采用 AST 白名单构造对象；不将用户字符串传给 eval、sympify 或 parse_expr。SymPy 官方提醒 parse_expr 使用 eval，不适用于未清洗输入：[解析文档](https://docs.sympy.org/latest/modules/parsing.html)。Poly 用于确切多项式运算：[官方参考](https://docs.sympy.org/latest/modules/polys/reference.html)。

本轮只支持题目声明变量的有限多项式、非零常数除法和常数底 3 的线性整数指数，规范化为变量与 3^n 的有理系数多项式。不做任意函数、变量分母、根式或一般指数的判分。输入、AST、次数、项数及系数规模均有上限；不支持格式返回 uncertain，不进入可靠技能测量。

增加 ex-03-01-002:p3 的 3^n 规则及房间分配技能；增加 ex-07-01-002:p2 的 n−1、m−k、n、m−1 规则及图删除技能。public_question 从审核规则获取填空数量，修复图删除题被导入为一个空的问题，原始教材数据不重写。保留当前控件，展示必要输入约定。

判分按各空等权；受限范围内用规范式判相等，不用有限采样推断恒等。无法解析任一填写项时整个小题待核对，避免不可靠作答影响学生状态。版本、无帮助要求、删除保护及学生隔离沿用既有机制。预计规则覆盖 41 小题、15 技能。

验证包括代数等价、伪装有限采样的错式、解析拒绝/规模边界、两道题的实际 API 和 worker、四空控件契约、技能反馈和完整记忆回归。使用临时数据库与模拟模型，不运行真实模型 API。
