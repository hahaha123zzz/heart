# 第九阶段结果：规则题技能映射及教学反馈

## 已完成

把现有练习结果接成了可追溯的技能记忆：

练习提交 → 服务器规则再核验 → 技能观测 → 按技能汇总 → 统一记忆检索 → 教学规划及回答输入。

当前题库有 341 题、788 小题。本阶段人工审核并映射了其中 17 个已有确定性规则的小题，覆盖 7 项技能：集合确定性、集合非空性、属于与包含、差集与子集、集合列举、否定真值表、复合命题真值表。其余题目仍使用原有练习流程，不自动升级为可靠能力测量。

## 数据及可靠性

- 新增 exercise_skill_observations 表；记录学生、来源知识点、练习事件、题号/小题、题库版本、映射版本、核验状态及诊断候选。
- 映射绑定题面、小题和规则答案指纹。题库或映射不一致时，不生成技能估计。
- 只有无帮助且与服务器规则判分一致的作答，才进入技能估计。AI 评分、解析失败、获得提示的作答不进入。
- 每个不同题号/小题只取最近有效观测；重复提交相同小题不会增加独立小题数。
- 临时采用初值 0.5、alpha=0.4 的 EMA。该数值未校准，不是正确率概率，也不等于全章掌握度。
- 错题标记待复习，诊断方向仍需确认，不自动写成已确认误区。
- 技能摘要接入 MemoryContext 字符预算和学生状态派生字段；TeachingPolicy 可建议围绕薄弱技能复习、降低难度和检查。
- 管理页显示技能估计、独立小题数、待复习状态及来源题号/事件。

## 删除及异步边界

提交排队时保存当前知识点的记忆删除版本；完成批改时在同一事务检查该版本。用户在排队中或批改中删除记忆，晚到结果仍保存练习成绩，但被排除在事件、技能记忆和原始练习检索之外。删除后的新提交正常使用新的删除版本。

内部删除版本不出现在排队/批改的公开 result 中。兼容旧的无标记排队记录时按版本 0 判断；知识点已经删除过时，保守排除这类旧结果。原有直接同步记忆写入调用保留兼容接口。

## 当前限制及使用方式

技能估计仅针对当前题库/映射版本，不回填历史提交；旧观测保留审计用途。版本变更后需重新加载练习题库，旧版本提交返回 409。现有版本筛选可能不再展示旧版本草稿/提交，但原记录保留。

来源知识点沿用既有导入数据：集合规则题归属“1.1.3 外延性公理与子集合”，真值表题归属“4.1.4 语句的形式化”。细分技能名称描述实际考核能力；这一步没有修订题库的原始小节归属。

教学验证证明技能信息进入真实 Planner/Generator 的模型输入；尚未衡量真实模型遵循建议的程度和学习效果。

体验路径：在测验练习中独立完成上述规则题，进入“个性化设置 → 学习记忆管理”，展开对应知识点查看技能记录，再围绕该知识点提问。要看到最新代码，需按原项目启动方式重启应用。
