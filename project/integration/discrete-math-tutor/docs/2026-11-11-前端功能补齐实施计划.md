# 前端功能补齐 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把已有后端能力接到界面上：学习者页、学习记录三标签、正式复习队列、设置四标签、教材搜索，以及 4 个掌握路径写动作和记忆条目管理。

**Architecture:** 继续用宿主原生 JS + 现有 CSS token，不引入框架；原生 React 面板只在既有挂载点旁边共存，不重建 bundle。新增一个通用 `GapUI`（标签/抽屉）和 3 个功能文件，后端只加一个受控写接口和一个记忆投影动作。

**Tech Stack:** 原生 JS（IIFE + `window.<Module>`）、FastAPI + Pydantic、SQLite 仓储、Playwright（Edge）浏览器检查。

**Spec:** `docs/2026-11-11-前端功能补齐与组件规划.md`

## Global Constraints

- 不新增运行时依赖；前端只用 classic script + `window.*` 全局，遵循 `learning-review.js` / `native-memory.js` 的写法。
- 所有界面文案中文；新增样式只用 `workspace.css:2` 的 token（`--surface/--sidebar/--text/--muted/--line/--accent/--selected`），不引入新色板。
- 改动 `frontend/` 下任何 css/js，必须同步 bump `index.html` 里对应的 `?v=YYYYMMDD-<tag>`。
- 后端沿用现状：无登录态，身份只来自 `student_id`；新增请求一律 Pydantic 白名单校验，禁止 `extra`。
- 后端测试命令：`.\.venv-deeptutor\Scripts\python.exe -m pytest <file> -q`（其它 venv 没装 pytest）。
- 浏览器检查命令：`node scripts/check_gap_panels_browser.cjs --only=<block>`；脚本用路由拦截，不需要起服务。
- 已知基线：`tests/test_native_review.py -k application_review_api` 在改动前就因 `NativeTurnBridge.learning_service` 缺失而失败，本计划不负责修它，也不得用它当回归依据。
- 副作用动作必须二次确认：重做路径、删除记忆条目用 `window.confirm`；其余按钮点击后立即禁用并显示进行中。

## Review Focus

1. **空数据**：`/profile`、`/evidence`、`/lesson` 对无记录学生返回空对象/空数组/`null`；任何一处抛错都不能让整页停在加载态。
2. **超长文本**：`evidence.source_quote`、`misconception.description` 可能上千字；容器要 `overflow-wrap:anywhere`，列表行截断到 2 行。
3. **竞态**：切换学生或标签页后，旧请求返回必须丢弃（沿用 `refreshLearning` 的 sequence + owner + session 三重判断）。
4. **原生开关**：原生开启/关闭两种模式下，学习记录与设置页都必须可切换标签，原生面板不得重复挂载。
5. **键盘与焦点**：`Esc` 关闭抽屉/搜索并归还焦点；标签按钮维护 `aria-selected` + `role=tab`。
