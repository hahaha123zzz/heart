# 心理学跨会话记忆存储与召回验收

后续已完成三条真实模型跨会话复验，见《心理学跨会话真实回答验收-20261015.md》；下文保留本轮存储与召回测试的原始范围。

结论：跨进程持久化、完整历史召回和学生隔离检查通过。本轮验证记忆存储及检索接口，不将其等同于完整的大模型个性化效果验收。

## 方法

两个独立Python进程使用同一个临时心理学SQLite数据库。第一进程设置合成学生的明确偏好、写入学习记录后结束；第二进程重新加载模块，读取持久数据并检索。未使用真实学生记录或外部模型。

## 通过项

| 检查 | 结果 |
| --- | --- |
| 明确偏好持久化 | answer_length=0.8、example_density=0.9、learning_pace=0.2重启后仍可读取，来源仍为explicit_user |
| 超出短期窗口的历史 | “自变量和因变量混淆、喜欢做饭例子”的记录被35条无关记录挤出最近历史后，仍能召回 |
| 来源追溯 | 相关历史带有原始记录ID，检索范围为all |
| 学生隔离 | A的检索结果不含B的私密标记，B也不能读取A的旧学习记录 |
| 新学生空记忆 | 无记录时返回空items和空preferences，不生成虚构画像 |
| 原课程隔离 | 原有新旧课程隔离测试仍通过，旧库文件哈希不变 |

原始检查结果：`artifacts/psychology-cross-session-memory-acceptance.json`。本轮冷启动检索走FTS5，dense状态为not_initialized；没有以伪造向量代替真实检索。
