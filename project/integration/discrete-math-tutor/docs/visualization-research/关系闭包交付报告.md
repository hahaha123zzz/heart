# 关系闭包交付报告

2026-10-13。固定A={a,b,c}，自反、对称、传递闭包的只读预览已实施。

## 使用

刷新页面，打开关系示例3，点击“关系闭包预览”。默认传递闭包从原关系开始，点击“下一步”看到新增(a,c)，其前提(a,b)、(b,c)被强调。可切换自反/对称闭包，查看原关系、上一/下一步与最终结果；点击“解释这一步”向AI提问。原图和矩阵保持原值，预览矩阵的0→1表示补入关系。

## 实现边界

- 后台使用教材定义9.6的最小扩充计算，三种闭包均保留原关系。传递闭包采用正长度路径语义，用NetworkX独立核对；双向边会要求相应两点自环，孤立点不会自动获得自环。
- 新增只读closure接口，核对学生、会话、数学版本与测评状态。测评提交前页面隐藏入口，后台拒绝直接读取或以AI目标绕过。预览不新增学习证据、不改关系、数学版本或草稿。
- 闭包为独立只读画布和矩阵；原性质反例解释层在预览期间隐藏，退出时恢复。原关系数学版本变化会清理预览，布局变化保持当前步骤并更新位置。
- AI目标携带closure.kind与step，后台重算并验证步骤。上下文包含原关系与当前扩充关系及依据，避免以原关系的性质结论描述闭包。检索定位9.1.4定义9.6/定理9.10。
- 讲解引用记录保存最小闭包导航数据(kind/step/epoch)，刷新后可恢复当前会话中的图与步骤。旧版本、删除关系或删除闭包记忆后拒绝旧导航/在途提交。
- 没有将预览覆盖原图、自由论域、闭包组合、等价类或Hasse图功能。复用现有RelationRow、任务与引用记录，不新增状态表或修改旧表结构。
