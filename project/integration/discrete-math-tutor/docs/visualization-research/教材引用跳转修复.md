# 教材引用跳转与自动高亮修复

2026-10-13。

## 原因

截图里的“教材来源（PDF第8页起）”是来源字符串，而不是 PDF 坐标。原前端只有 pdf_references/selection_ref 生成跳转按钮，来源文字本身是普通 div。后台补引用还要求回答包含 [n]，且编号必须在检索片段开头，因此无编号提示或编号位于片段中间时没有可点击引用。旧记录也可能只有来源而没有坐标。

## 修复

- 来源文字统一成为按钮。已有坐标直接打开；旧记录点击时通过本地 citation-location 接口补定位，不重新请求模型，不发送对话到外部服务。
- 定位校验本地教材文件名、小节及 PDF 版本。不能把来源文字中的页码当作坐标；非法教材返回422。允许同一本教材的原 Word 文件名和对应 .txt 文件名。
- 优先使用回答与来源共同出现的编号定义/定理；编号不必在片段开头。精确坐标不足时，仅高亮经验证的小节标题，并明确提示这是小节定位。
- 新回答没有 [n] 时，为界面原本展示的第一条来源补齐定位。保留已存在的多来源坐标，来源索引不重排。
- 前端缓存版本20261013-citation-fix。不修改阅读器数学或图交互逻辑，不自动声称小节标题是精确引用段落。
