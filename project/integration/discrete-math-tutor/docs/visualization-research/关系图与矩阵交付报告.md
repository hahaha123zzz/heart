# 关系图与矩阵交付报告

2026-10-13；固定非空论域 A={a,b,c} 的首版已部署。

## 使用与实现

Ctrl+F5 刷新本地页面，在聊天输入区选择“关系示例 3”，点击“关系图与矩阵”。默认 R={(a,b),(b,c)}：点击矩阵 a 行 c 列可添加 a→c；图与矩阵同时变化，传递性从不满足变为满足。点击对角线可添加自环；a→b 与 b→a 是两条不同的边。

- 图层使用 Cytoscape.js，有向箭头、自环与拖动；后台用 NetworkX DiGraph 和有限论域定义枚举验证五性质。
- 可选择自反、反自反、对称、反对称、传递，查看对应结果与具体存在/缺失序偶。非传递反例包含两条前提边和缺失的结论边。反例支持图矩阵同步标记和逐项查看，尚未实现自动播放动画。
- 图、矩阵和 AI 共享服务端规格。数学版本与布局版本分离，拖动不改变数学含义；修改关系后清空旧预测。刷新恢复已保存状态；未保存的输入只保证当前页面重绘时保留。
- 随机测评提交前 API 和页面隐藏五性质结果及反例。填写五项判断后提交，反馈逐项检查。首次作答锁定，订正创建同关系的新记录，保留原结果并按辅助作答记录。
- 保存草稿、提交、布局和改边使用版本检查及请求收据。回包丢失使用同请求 ID 重试，不能重复记证据。会话隔离、知识点删除及 epoch 防止迟到写回。
- 选中性质及元素对后提问，发送明确 artifact_id、数学版本、property 和 pair；后台读取权威快照，以第九章 9.1.3 关系的基本特性作为教材检索锚点。
- 未提交测评强制仅提示，生成输入不包含后台判定/反例；质检独立读取权威结果。请求提示后不能记录独立作答；文字理由保存但不评分，不自动增加掌握度或推进课程。

## 复用范围

复用现有图组件生命周期、测评事务与幂等、TaskService、教材 RAG 和 MemoryManager。五性质枚举实现针对固定三元素论域；没有部署新的在线模型或引入知识图谱服务。

新增关系规格、服务、API、前端组件及 relation_artifacts/relation_operations 表；未修改欧拉图的无向简单图规格。真值表服务通过可替换 operation_model 复用草稿收据逻辑。
