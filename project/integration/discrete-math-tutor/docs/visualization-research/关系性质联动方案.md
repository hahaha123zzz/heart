# 关系性质的图与矩阵联动

2026-10-13。根据已提出并获用户“继续”确认的下一批范围实施。

选择五种性质时，图和矩阵共享当前后台判定与反例。已有依据标为实线及“已有”，缺失关系标为虚线及“缺失”；缺失边仅为解释层，不写入关系或布局。颜色配合文字、线型表达，不依赖颜色区分。

不满足性质时，提供全部反例以及逐项查看按钮，点击后高亮对应序偶。传递性标出两条前提边和缺失结论；对称标出已有边与缺失反向边；反对称标出不同点之间的两条反向边；自反/反自反定位自环。成立时高亮检查涉及的格及已有边，并明确这是固定三元素论域的完整检查。反自反的对角线0表示检查范围，不画成缺失反例。

未提交测评不显示依据按钮、图中虚线或矩阵提示。状态、版本、性质变化后重建解释层，防止旧反例滞留。选择解释步骤不改变数学状态、草稿、学习证据或掌握度。

AI回答增加“查看图中依据”，使用已核验关系ID、版本、性质与元素对回到相应组件。图已变化、已删除或不在当前会话时提示重新提问，不用旧回答覆盖现有图。将最小定位元数据随现有引用记录保存，刷新恢复入口。

复用Cytoscape.js、本地组件及后台验证器。选择自动联动加逐项按钮：比单纯颜色更容易解释，较自动播放保留学生操作节奏。首版不增加自动动画时间轴。

实施：组件解释层与矩阵标记；AI入口及历史元数据；针对性浏览器验证提交前隐藏、缺失边不入库、版本拒绝、状态更新清理和刷新恢复；更新交付报告。只对影响数学数据和测评隐藏的边界做必要验证。
