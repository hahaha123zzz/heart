# 阶段 A：消息生命周期实施报告

日期：2026-10-12。范围：聊天渲染与历史消息标识。阶段 B 图组件尚未实现。

## 已完成

- `frontend/chat-renderer.js`：按消息键维护 DOM，只更新变化的进度、正文、引用、澄清、记忆摘要、插图与重试区域。固定互动容器不随文本更新重建。
- 提供本地组件 mount/update/dispose 接线；同消息同组件更新复用实例，消息删除时释放实例。挂载失败清理容器，单个释放异常不阻断其余消息清理。
- `frontend/app.js`：历史消息保留 conversation ID；流式消息使用固定客户端键，done 更新同一个消息对象，不重新挂载。旧服务未返回 ID 时仍可显示。
- 原文/处理记录的折叠状态在所属区域更新时保留；上方阅读时追加消息不强制滚到底部，接近底部则跟随。
- 正文变化时才调用公式渲染；PDF 公式库 ready 事件补渲染已有正文。
- `database/repository.py` 和 `web_api.py`：历史 API 返回已有数据库行 ID；不新增表或迁移。
- `frontend/workspace.css`：适配新正文容器，保留原换行和用户气泡边距；入口资源版本更新。
