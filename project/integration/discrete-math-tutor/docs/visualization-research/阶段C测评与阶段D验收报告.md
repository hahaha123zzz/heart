# 阶段 C 测评与阶段 D 验收报告

日期：2026-10-13。状态：阶段 C 提交闭环及阶段 D 测试账户验收完成，已更新本机预览服务。

## 本轮实现

- 辅助图新增“做一道新图练习”。服务端在四顶点环、路径、星形、环加对角线中生成题目并置换顶点标签；客户端不能上传已知答案的测评图。
- 测评图固定边集，布局仍可拖动。提交前 API 和页面均不返回度数、奇度顶点、欧拉判定；提交后展示计算结果和逐项反馈。
- 作答包含各顶点度数、连通性、欧拉性质预测和可选文字理由。NetworkX 按教材定义 7.18 的全顶点连通约定验证前三项；文字理由仅保存，不自动判分。
- 每张测评图一次提交；保存图快照、revision、epoch、学生答案、验证器版本及收据。同一 request_id 的相同请求重试返回原收据，不重复生成证据；改变内容或另发提交返回冲突。
- 针对未提交测评图的 AI 请求由服务端标记 assisted，不信任客户端的提示标记。未提交测评图和提示图的回答范围固定为 hint；修改按钮 action 不会解除限制。生成阶段不提供后台 evaluation，质检仍读取权威结果核对答案泄露。
- 自定义答案、提示按钮、拖动操作不会自动更新掌握度。只有明确提交产生学习事件与原文证据；复用 MemoryManager、evidence_policy、既有学习事件/证据表与检索索引。
- 当前“独立”表示本张新测评图上未请求 AI 辅助；该标记的范围是结构化作答，不证明自由解释正确，也不代表全面掌握或学习增益。

## 存储与接口

新增 `graph_attempts` 表，外键指向 `visualizations`，删除图/关联消息/学生时级联删除。忘记知识点同时删除测评图、收据、对应学习事件和证据，memory_epoch 防止延迟提交重新写回。

新增 `POST /api/visualizations/{artifact_id}/submissions`。账户、会话、版本、epoch 在服务端核验；提交、反馈、事件和证据共用 SQLite BEGIN IMMEDIATE 事务。证据保存失败时提交收据一并回滚。

## 多图对话发现与修复

1. 恢复上下文时此前没有重建历史互动图，造成“这个图”的候选缺失。现在仅从同会话任务恢复合法且版本未变的图。
2. 当前图和历史图一起成为执行目标，造成检索被旧图干扰。现在执行目标只绑定冻结快照中的 artifact_id；历史图只作为澄清候选。
3. 模型输出 `missing_slots=[target]` 却同时给出 `intent=continue`，此前被当作解析失败。现在只将这种矛盾保守转为澄清，随后仍执行全部严格字段与资源引用校验；非法 ID、非法能力、自由改写仍拒绝。
4. 选择澄清选项后重新校验该图版本。图已改变或删除时拒绝恢复旧任务；不会悄悄切换成另一张图。
5. 用户连续要求解释不同图时，旧规则把连续三轮 `direct_explanation` 当作失败。显式任务现在允许按用户要求重复教学动作，完全相同回答仍被拒绝。
6. 澄清恢复后的问题只写“这张图”，原来的关键词过滤未触发，仍可能附图 7.19。当前图有权威快照时，除非用户指定教材图号，统一不追加其他教材插图。此项最终由完整编排回归检查验证。

## 体验步骤

1. 打开 `http://127.0.0.1:8000/`，按 Ctrl+F5。
2. 点击输入区“图论互动”，进入图后点击“做一道新图练习”。
3. 填写度数、连通性和欧拉性质，点击“提交判断”查看反馈；刷新后原文和反馈应保留。
4. 再开新题，点击“只给第一步提示”后提交，反馈应标为辅助作答。
