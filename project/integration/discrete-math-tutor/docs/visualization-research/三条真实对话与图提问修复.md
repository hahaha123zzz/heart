- 真实接线复测还发现解释被课程第一步目标压缩为反问，提示充分性核验又被扩大成完整判定。这两个问题也一并修复，没有关闭质量门槛。

## 修改内容

### 教材和任务范围

1. 话题切换标志要求实际 switch_topic/new_goal，不再以小节标题变化判断。
2. 自定义顶点/边集问题不泛化匹配教材插图；普通配图要求来源章节和小节匹配，明确图号查询仍可检索原图。
3. 图号与图注去重，避免“图7.19 图7.19：……”重复。
4. 明确解释任务必须完成用户请求的计算、条件核对与结论，不能用反问替代当前实例解释。
5. ContextSufficiency 由已校验任务传入 full/hint 范围。完整解答仍核验全部所需依据；第一步提示只核验该步，缺少必要定义仍拒绝。

### 图与 AI 接线

1. 增加 visualization_target：artifact_id、expected_revision，以及明确按钮的 explain/hint 动作。与选区、小题分别提问，不接受客户端计算结论。
2. 服务端检查图的学生/会话归属、功能开关、图版本和 memory_epoch；读取边集并用 NetworkX 再计算，构建独立辅助图对象和冻结快照。
3. 快照进入现有 TaskService、RAG、MemoryManager、生成和质量检查。辅助图事实不占教材引用编号，教材定理仍有原文引用跳转。
4. 提问中改边时拒绝旧回答写入，并释放原任务；最后写入与图版本检查共享事务。布局版本独立，拖动不使回答失效。
5. 图组件增加“解释当前图”和“只给第一步提示”，使用组件当前确认的图版本；保存回调同步前端缓存。
6. 本次两个明确题面形式可自动创建辅助图：明确 v1..v4 的边集，以及审核模板“四节点环增加 v1-v3”。不能解析的描述保留文字流程，不声称支持通用图理解。
7. 新增 visualization_display 表保存展示模式，兼容旧图，无需 ALTER 原表。仅提示的新图 API 隐藏度数、奇度点和最终判定；布局和边操作后仍隐藏。内部快照计算结果供核验，聊天结果不返回这份内部 evaluation。
8. 所有图仍标为辅助示例；旧教材引用和图片记录保留，修复不重写旧回答。
