# 第六阶段结果：记忆查看、更正与删除

日期：2026-10-11

## 用户入口

现有「个性化设置」页新增可折叠的「学习记忆管理」，沿用已有页面样式，没有改造教材阅读器或新增独立管理页面。

- 查看显式偏好及其来源，选择知识点查看掌握估计、误区判断、最近证据/事件和后台摘要正文与来源。
- 在具体活跃误区下填写说明并提交更正。服务器只把该目标标为 dismissed，记录用户陈述，其他误区和掌握度不变；不会把用户否认当独立能力证明。清理该知识点旧的 gap/summary 缓存，后续新独立支持仍可重开误区。
- 清除单个设置偏好。旧记录没有明确来源时显示 legacy_unverified，保存设置后标为 explicit_user；更正、清除都在短事务中完成。
- 删除一个知识点的学习记忆；界面明确提示对话、判断和摘要删除，练习成绩保留，提供操作确认。

「建议复习」同时排除 dismissed 和 resolved，避免用户否认后仍被当作当前困难点展示。

## 后端与删除传播

新增测试账户管理接口：

|接口|用途|
|---|---|
|GET /api/students/{student_id}/memory?point=...|查看当前学生知识点及来源|
|POST /api/students/{student_id}/memory/misconceptions/{id}/correction|提交用户更正说明|
|DELETE /api/students/{student_id}/memory/preferences/{key}|清除一个显式偏好|
|DELETE /api/students/{student_id}/memory/points?point=...|删除整个知识点学习记忆|

接口仅开放已存在的 test 账户，未知账户 404，production 账户 403；请求字段、说明长度、知识点长度和目标归属有验证。这是当前本机 Demo 的学生范围隔离，**不是生产身份认证**。

新增 memory_controls / memory_exclusions / memory_changes。按知识点删除在同一事务内移除已明确关联的对话、证据、状态、计划、误区、策略观察、后台任务/产物及检索索引。同步清理该知识点修订及其他知识点快照中按来源可定位的副本。只保留无旧正文的 epoch/删除元信息。

旧练习业务成绩保留，但已关联提交 ID 加入记忆排除表。索引重建不重新召回；晚到的同提交批改回调也不会重新写证据。之后的新提交可形成新记忆。

删除推进知识点 epoch；普通聊天与 PDF 圈选在保存前核对读到的 epoch。删除前开始的旧请求不保存、不发布旧解释。后台摘要租约与向量哈希检查继续生效，晚到写回不会重建被删来源。客户端删除后清理当前聊天显示，其他知识点的服务端数据仍保留。

## 范围和限制

- 本轮没有重启服务，运行中的旧进程还未加载新功能；新表由下次 init_db 建立。实际密钥/环境文件未修改。
- 删除粒度是整个知识点，不是任意一条能力证据后无损重建状态。不能可靠恢复归属的旧孤立对话不猜测删除；没有已关联事件/索引的旧练习也不能自动判断归属。
- 显式偏好清除针对保存的设置键与其快照；不会自动删掉所有历史聊天中可能涉及该偏好的句子。用户否认不等于数学能力验证。
- 原始练习成绩/答案保留于练习业务记录；本功能删除的是学习记忆。尚未实现全平台个人数据删除或生产登录授权。
- 尚未做生产数据迁移、真实模型质量/费用评估或浏览器端到端验收，不据隔离检查宣称线上教学准确率。
