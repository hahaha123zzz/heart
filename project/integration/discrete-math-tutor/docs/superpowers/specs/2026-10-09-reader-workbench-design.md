# 教材阅读工作台改造设计
日期：2026-10-09
状态：待审阅；本次已检查现有代码，尚未实施改造。

## 目标
将首页教材区与课程学习页统一为阅读工作台。承接已经讨论的文字、图片、公式选中提问及相关学习记忆功能。保留其他统计、测验与设置入口。

## 方案比较
1. 推荐：重构现有 HTML 阅读器。沿用 Word 有序内容块、公式原图、表格与绘图定位，新增独立工作台与可验证选区。可直接对接当前后端，支持宽度自适应。
2. 转为 PDF 阅读器：原始分页更完整，但需要生成、管理 PDF、文字层和页坐标，并重新对齐现有知识块。适合后续需要原书页码的场景。
3. 仅调整字体与配色：成本最低，无法解决阅读空间、图像放大和选中提问的问题。

## 界面与交互
- 进入首页即进入阅读工作台；课程学习入口复用同一阅读区域与当前小节，避免两套渲染和选区逻辑。
- 阅读时缩小平台导航，取消占用阅读区域的宣传横幅和步骤编号；通过明确的返回平台入口访问测验、统计与设置。
- 顶部紧凑工具栏：教材名称、当前章/节、目录开关、字号、阅读主题、专注阅读、AI 面板开关。
- 左侧目录默认约 240px；支持过滤章节和小节、展开与收起、当前小节高亮。目录关闭后正文获得空间。
- 中央正文使用受控行宽，默认 18px 字号和约 1.9 行高；提供 16/18/20/22px 档位与浅色/护眼主题。样式设置保存在当前浏览器。
- 正文连续滚动；底部显示上一节/下一节。记住每节阅读位置，返回时恢复。此进度表示滚动位置，不作为掌握程度。
- 右侧 AI 约 360px；可收起。阅读与回答并排，课程学习中提问也不跳离教材。
- 平板与手机使用目录抽屉、AI 抽屉；正文优先占据屏幕，避免把所有面板纵向堆叠。
- 公式保留教材原图与原生上下标。图像按原比例显示，表格局部横向滚动。点击图片或公式出现操作菜单；“查看原图”打开页面内灯箱，支持缩放、复位、关闭及 Esc。
- 教材原生图号与图注保留；来源文件名、未核定标签和 Word 锚点等自动元数据不出现在正文。

## 选中提问
- 划选文字或表格文字后显示“向 AI 提问”；点击完整图或公式可选择该对象。
- 保存选择快照，弹出按钮不能让选区丢失。输入区显示引用预览，可取消、改问题后发送。
- 后端以章节、小节、教材版本、稳定块 ID、文字偏移或对象 ID 重建内容；不依赖“这张图”关键词猜测位置。
- 取所选位置及邻近正文、原图/公式；最多两张模型输入图片，超过限制提示缩小选区。
- 读取当前学生相关学习状态、已有误解、偏好和有限历史。无记录时不编造学习记忆；提问本身不计为掌握或错误证据。
- AI 处理阶段显示定位教材、读取学习记录、生成讲解、核对引用和保存记录。显示实际处理状态，不展示隐藏思维链。
- 回答保留结构化引用，点击回到教材相应块并短暂高亮；刷新可恢复引用。选区的问题和跟进引用与原章节绑定。
- 本次支持完整图片/公式对象和文字范围；图内矩形裁剪独立作为后续增强。

## 代码边界
- 新建独立阅读器前端模块处理布局、阅读设置、选择菜单、灯箱及定位；现有 app.js 保留平台导航、测验、统计和聊天请求协调。
- knowledge/content.py 增加稳定块位置、可选文本范围及教材版本。
- 独立教材选择解析模块负责验证选区与构建上下文；独立学习记忆筛选函数限制范围和数量。
- ChatRequest 增加可选 selection；普通问答仍走现有流程。选区提问优先解释所选内容，生成与质检都收到实际原图。
- 对话数据保存可恢复的选区引用；兼容旧记录。接口返回错误提示而不是静默丢弃或使用错误教材位置。

## 验收
- 桌面 1440px 与手机 390px 正常阅读；正文无页面横向溢出，表格自身可滚动。
- 目录/AI 收起、主题字号、专注模式、上下节、位置恢复、灯箱键盘关闭与触屏操作可用。
- 第 7 章文字选择、第 8 章匹配图、第 3 章公式均定位正确；表格选文保持数学符号。
- 学生记忆隔离；无历史不编造；选择不推进课程步骤。
- 无效块、异节图片、旧版本、越界偏移与过多图片明确失败。
- 普通聊天、实时状态、统计和测验保持可用；浏览器无脚本错误。
- 使用已授权 API 对图片与公式各做一次真实问答验证，并保留结果与界面截图。

## 自审
本次不切换 React 或 PDF 技术栈，不重新导入教材，不把低清公式放大宣称为清晰重绘。改造聚焦阅读和选中问答，图内裁剪暂不作为完成标准。
