# 教材与练习分离

用户已确认：教材移除习题，统一在测验练习页展示；阅读和 AI 学习后，用户点击按钮跳转到相应章节。

原版 PDF 保留供圈选裁图与引用；生成正文 PDF 与练习 PDF，依据练习标题到下一大节标题拆分。正文 PDF 保留页面尺寸和坐标，建立正文页到原页映射。例题保留。练习页保留现有可评分选择题，新增完整原教材练习 PDF（原题未提供标准答案，不伪造评分）。

测验章节独立于教材章节，练习提交使用试卷自己的章节。教材与答疑入口明确选择相应章节；AI 选区解释优先使用选区所属章节。用户手动确认学完，不从 AI 措辞推断掌握。测试正文无练习标题、全部章节标题可定位、原页选区回传与引用恢复、跳转和独立章节切换。
