# 教材问答系统产品契约

## 范围

系统只回答教材中已有的定义、概念、定理、性质、公式含义、区别和教材解释。

系统不做题、不计算新题、不证明新题、不生成新例子，也不用模型常识补充教材没有的内容。

## 固定流程

1. 判断是否属于教材内容问题。
2. 识别概念、对象、属性、章节和必要上下文。
3. 用原问题、规范术语、别名和小节标题多路检索。
4. 返回完整教材知识单元，保留定义条件、定理条件和公式说明。
5. 按“直接回答、教材依据和关键条件、简短解释、教材引用”回答。
6. 发布前逐句核验依据；核验失败先重新检索，仍失败则明确拒答。

## 固定拒答

当前系统只回答教材中已有的定义、概念、定理、性质、公式含义、区别和教材解释，不做题、不计算新题、不证明新题，也不使用教材外知识。

## 评测原则

- 旧题只用于回归，不用于证明泛化能力。
- 新题法、相似概念混淆题和教材外问题必须单独冻结。
- 分别统计章节命中、概念识别、条件完整性、逐句支持、错误引用、教材外内容和正确拒答。
