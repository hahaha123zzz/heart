# 记忆系统第四阶段结果：策略观察与规则反思

日期：2026-10-11

## 已完成

在当前事件、证据、修订事务上新增 strategy_observations，沿用先前调研的来源绑定和经验库思路，没有复制开源源码或新增记忆框架依赖。

1. **修正时序归因**：本轮学生作答关联上一轮同知识点已提交教学动作，不能用它评价尚未发生的本轮策略。保存两个事件 ID、原文证据 ID、知识点、实际教学动作、难度、提示级别、结果、理由和规则版本。
2. **三态观察**：独立作答且有可追溯原文时，掌握估计上升至少 0.08 记 progress，下降至少 0.08 记 regression，其他情况 unknown。无前一教学来源、旧事件无上下文、提问/辅助作答、无原文、变化不足阈值均不能记为失败。
3. **受约束规则反思**：按知识点、教学动作、难度和提示级别分组，输出进展/回落/未知计数、来源 ID 和限制说明。至少三条已测量观察才生成 0.4–0.6 的弱权重；unknown 不进入分母。
4. **接入真实规划**：MemoryManager 提供规划用画像副本，保留原偏好但不读取旧无来源 EMA 作为权重。TeachingPlanner 首次使用默认 medium/提示1条件，StrategyRouter 使用规划确定的难度/提示条件；观察只能轻微影响候选评分，TeachingPolicy 不据它覆盖当前教学约束或禁用策略。Router 最终可能选择其他难度，这些弱权重不等于最终动作的精确效果预测。
5. **统一记忆上下文**：策略反思进入 MemoryContext.strategy_memory，与历史和状态共用字符预算；模型看到的是历史数据，而非新的教学命令或数学证据。
6. **恢复与一致性**：近期动作从已提交事件读取，重启可恢复。重复回合不会重复记录；冲突、教学错误、质检拒绝不新增观察；源事件失效后不再参与汇总；学生删除级联清理。观察纳入修订快照，事务失败全部回滚。

旧 teaching_effectiveness 数据和 update_effectiveness 接口保留兼容，但正常教学提交不再按 success 参数更新旧 EMA。旧 push_recent_move 缓存写接口保留，实际近期动作读取以持久事件为准。

## 限制与下一阶段

- 当前是**确定性规则反思**，尚未实现后台 LLM 摘要、持久任务队列、失败重试或任务重放；本阶段没有把这些未完成项标为已完成。
- 观察结果来自已有 AI 暂定掌握估计，不是规则判分正确性、不代表因果教学效果。0.08 和三次样本阈值均未经真实学生数据校准；不同事件不保证任务难度完全一致或证据语义独立。
- 同一教学来源只看相邻事件，跨长时间、跨多个动作的归因暂不支持；讲解/提示后的作答按现有保守 EvidencePolicy 多数归为 unknown，不能拿 unknown 比例推断教学无效。
- 缺少稳定 concept_id/course_id、会话间隔限制与技能评分映射，目前按单课程 Demo 的知识点字符串隔离。
- 按学生/知识点读取全部观察后汇总，适用于当前 Demo；规模化后需增量汇总与性能评估。
- 未重启的服务尚未加载这些修改。新表随下次 init_db 建立，旧历史不伪造反思回填。

下一步：持久后台记忆任务，把可审核的摘要/反思生成与在线教学解耦，补充幂等、重试、来源失效和删除传播。继续以原始证据为权威，候选反思不得自动改变掌握度或误区状态。
