## 核验范围

支持声明变量的有限多项式、有限整数次幂、非零常数分母，以及计数题声明的底数 3、变量 n 的有限线性整数指数。以 3^n 作为规范式中的指数基元，用精确有理系数比较；不使用有限数值采样来判定恒等。

可接受：3^n、3^{n}、3^(n+1)/3、LaTeX 分式形式，以及 n−1 与 (2*n−2)/2 等代数等价形式。乘法须写 *。

不支持任意函数、未知变量、变量分母、一般根式或一般指数，例如 sin(n)、n/n、9^n、3^(n/2)。这些输入保守返回待核对；不因不支持格式判错，也不进入可靠技能测量。

上限包括规范化文本 256 字符、AST 80 节点、最多 3 个声明变量、多项式次数 12、项数 256、系数 1024 bit；乘积和幂展开前也检查规模，避免先无界展开。

每空等权判分。任一填写项超出规则解析范围时，该小题整体待核对。可靠的部分正确结果可形成限定技能反馈，仍不改变全知识点掌握度，不自动确认具体误区。

## 使用与限制

重启应用并重新加载题库后，可在第 3 章三房间分配题填写 3^{n}，在第 7 章图删除题依次填写四个表达式。完成独立作答后，记忆管理可显示新技能；得到提示后的答案仍不计作独立测量。

新题目和规则改变全局题库/映射版本；本轮还把判分实现纳入题库版本指纹，避免判分语义变化后混用旧证据。旧记录保留，但不回填或迁移到当前版本技能摘要；旧页面提交需重新加载。

有限多项式和当前指数规范化是本轮范围，不代表已支持全部教材公式。技能估计仍未校准，AI 是否实际遵循建议及学习效果尚未实测。后续扩展应按题目定义域与答案结构逐类接入，保留无法确定的结果。
