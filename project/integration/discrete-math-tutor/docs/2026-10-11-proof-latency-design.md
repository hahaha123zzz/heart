# 证明审核并行优化

教学质量与证明审核读取同一份不可变输入，原链路先教学后证明。保持五项数学核验、推理配置与发布门槛，改为最多四个审核任务的共享线程池并行执行。所有结果均须汇合，任何未通过、格式无效或异常都阻止发布；普通回答仍只有教学检查。记录教学、证明与总墙钟耗时，教学检查针对证明请求限制25秒且不重试，证明保持60秒界限。

替代方案：合并审核可减少模型调用但改变审核独立性；降低推理预算已有漏检和截断证据，不采用。本轮选择保留两个检查的并行方式。

冻结新题四题，先测两题串行基线，再同条件测并行；其余两题检查新题泛化，不用测试结果调整数学提示词。模型随机性、并发和外部API波动均须在报告说明，不能把估算节省当作实测整轮提速。
