# 证明核验与 GPU 首次推理排查设计

## 证明核验

在当前最终质检发布门槛基础上，对证明讲解单独核验变量作用域、已知前提、推理有效性、非循环性和教材归属。模型只返回固定检查项、短引用和核验结论，不输出详细思考链。缺项、重复项、不存在于回答中的问题引用、异常或超时不得作为通过。该检查仍是模型审查，不声称形式化验证。

生成时明确局部变量与边端点。质检反馈作为待核实资料传入；核验失败只指出问题，不将未验证的修复推导注入系统事实。

## GPU 排查

已有轨迹中首个CUDA Equal调用占41.4秒，整个首次run47.8秒；另有常规启动约288秒。先以同一模型、同一输入、真实CUDA provider和分阶段计时验证显式持久化缓存；冷/暖进程结果分开，检查分数一致，保留原配置作为对照。只在证据支持后调整应用默认初始化设置。
