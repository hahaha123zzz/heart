# PDF 文字划选统一教学循环验收

日期：2026-10-24。范围：用户选定的第一种方案，只接入 PDF **文字**划选；不替换图片框选、作业、真值表、关系或专用互动图的入口。不推送 GitHub。

## 已交付

- 普通助教与文字划选共用 `run_agent_loop_turn`、DeepTutor 教学状态、工具循环、发布核对、SSE、持久化和任务幂等。新增的是取证适配器，不是另一套问答生成器。
- 服务端核验 PDF 版本、文件哈希、页码和坐标，重新提取原文；客户端预览文字不被当作证据。选区为主证据，最多补充同页同小节的三条附近完整文本块，每条引用能回到真实坐标；不自动扩成全书语义搜索。
- 支持没听懂换讲法、原题保持、原题恢复、作答反馈及“只讲不考/只提示”等约束。未附 selection 的明确续问可从同学生/会话/记忆 epoch 的最近成功任务恢复并重新验证；明确新主题或阅读位置变化不恢复旧选区。
- 换选区更换教学目标并清除旧待答题；本轮模型输入不带旧选区对话，但不删除页面历史。同一选区续问保留上下文。发布检查拒绝无事实依据的“没有收到选区”声明。
- 引用、选区和教学状态随对话保存；不因为选区讨论推进 Q5 正式活动/路径或标记正式掌握。保留原有 1800 秒任务有效期。
- 保留原有可选按需图示连接；待答题存在时不生成可能泄露答案的图示。本轮没有专门完成真实模型图示生成验收，不将此列为已验证能力。

## 真实模型与重启验收

独立服务：8001；独立数据库：`.runtime/selection-loop-qa-20261024.db`；实际模型为已配置 DeepSeek，非 mock。

证据目录：`.runtime/selection-shared-loop-20261024/`。可重放脚本：`scripts/check_selection_shared_loop.py`，依次 start → 重启独立服务 → finish；switch 用于最终切换选区复验。

1. 使用实验心理学第二章实际 PDF 坐标，附故意伪造的客户端预览。SSE 返回已发布回答及精确引用；伪造文本未进入结果。
2. 同一选区“没听懂”改变教学策略，保持原题及 question_id；相同 request_id 重放不创建另一题。
3. 重启后历史恢复；不附 selection 也能找回原题，确定性原题重放为 0 次模型生成。
4. 不附 selection 的实际答案被判为正确并反馈，仍非正式掌握。
5. 最终 switch 复验：重新解释原选区后切到“操作性自变量”，目标身份改变，无旧待答题，回答实际解释新段落，未再谎称没有选区。

早期复验曾发现真实模型在切换目标后声称“没有新段落”；不是单纯状态测试能发现的问题。已增加当前原文明确指令、发布约束和跨选区模型历史隔离，再次使用真实模型复验通过。

## 边界与回退

选区不足以支持问题时应说明缺少什么并建议扩大选区，不假装看过图片，也不跨全书补全。图片框选/作业仍是原流程。多轮恢复遵循原任务 30 分钟有效期及账号/会话隔离，不承诺无限期恢复。

回退：将 `SELECTED_TEXT_AGENT_LOOP_ENABLED=0` 并重启平台，即恢复原文字选区入口；无需回滚数据库。本机 `.env`、教材数据、模型缓存和验收数据库均不纳入提交。既有 `scripts/parse_converted_textbook.py` 修改不属于本轮，保留且不提交。
