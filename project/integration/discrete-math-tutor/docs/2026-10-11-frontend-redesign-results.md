# 前端改造交付记录（2026-10-11）

## 已完成

按用户授权实施最新前端改造计划，沿用当前 HTML/JavaScript 页面、React PDF 阅读器和后端接口。

- 单一三栏工作台：左侧导航与教材目录，中间教材/作答/记录，右侧持续保留对话。
- 灰白与低饱和度灰蓝配色，浅蓝用户消息，15px 对话正文；移除宣传横幅和卡片嵌套。
- 可折叠导航；拖动、键盘和 70:30 / 60:40 / 50:50 快捷比例，按学生保存布局与输入草稿。
- PDF 页码、滚动位置和缩放按教材版本保存；切换练习时保持阅读器，不因界面切换重复挂载。
- 圈选文字、图、公式后向右侧提问，保留真实上下文预览。引用定位与提问附件分离。
- 每条核验引用保留原编号、章节、页码和定位；裁图可展开，旧历史沿用兼容路径。
- 回答未完成保留处理记录，可恢复原问题与选区后明确重试。
- 练习列表移入左栏，默认聚焦当前小题，可展开整题；隐藏控件不卸载，保留 MathLive 和构图草稿。
- 小题提示与 AI 讲解在右栏显示，使用原 question_id、part_id 和 version，不写入教材聊天历史。
- 学习统计、活动、错题、建议复习与近期对话整合到学习记录；设置保留偏好与记忆管理入口。
- 新学生暂无记忆时显示清晰空状态。
