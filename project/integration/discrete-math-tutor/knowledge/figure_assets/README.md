# 教材图片素材

本目录的 `figure_7_8.png`、`figure_7_20.png` 和 `figure_7_23.png` 均是从原始 `第7章图（新）.doc` 提取的完整 PNG。图片内容、SHA-256 与 Word 对象位置均已核对，引用信息见 `../figure_catalog.json`。

- 图 7.8：Word 浮动图片锚点 6081，紧邻练习 7.1 第 7 题的编号迷宫；图片宽高比与原对象一致。
- 图 7.20：图像内容与例 7.12 的哈密顿回路、正十二面体说明一致。
- 图 7.23：Word 图片锚点 18236，紧邻定理 7.14 的 `n=5` 示例及“图7.23”图注；图片宽高比与原对象一致。

可运行 `python scripts/extract_doc_png_candidates.py` 查看十章旧 `.doc` 内可直接扫描的 PNG 候选。该脚本只识别 PNG，不覆盖旧 Word 中的 WMF、EMF、OLE 公式与其他对象；批量导入仍需解析版面并核对图号和位置。
