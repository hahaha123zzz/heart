# 四阶段交互课程

## 调用条件

用户明确说“交互式讲解 / 交互课程 / /aha 主题 / /3b1b 主题”时调用。普通“解释一下”不自动变成课程。利用已知背景，不重复询问画像。

用户说不要图解、只要文字时不调用。正在作答、只要提示、待答题未完成或缺少可核验教材来源时不生成，不能泄露答案。明确请求可以触发；一般自动补图仍遵循宿主开关。

## 执行方式

严格使用 puzzle → explore → concept → challenge 四阶段。puzzle/explore/challenge 各给2至4个可比较情境，每个情境绑定图中节点和具体反馈，点击后改变关注节点；不是只翻文字。先探索再命名概念。反馈是辅助学习，不写正式分数、掌握度或复习状态。

换例子必须同时换图：阶段可提供 `graph: {nodes, edges}`，选项的 `node` 必须指向该阶段图中的节点。迁移挑战不能沿用与题干不符的旧图；不提供 graph 时才复用课程主图。

教学准备阶段通过 read_skill 阅读本文件；实际产物由已核验回答后的宿主 visualization.on_demand 生成。先发正文，再异步补图。只使用当前教材来源和已接受的回答，宿主验证参数、逐字证据、教材位置和图文一致性后才保存。未生成成功不声称已完成。不执行上游技能里的 shell、联网、任意脚本或浏览器存储命令，不创建第二套学习状态。
