# 教学技能入口

每轮回答前，agents/teaching_skills.py 先向模型提供仅有 read_skill 的读取阶段，第一个工具调用限定为读取本目录 SKILL.md。之后模型根据学生问题和总指南，自行选择技能、读取必要 references，最后回到原回答流程。读取阶段不产生学生正文，不开放网络或写入工具。指南与选中技能按轮重新读取，恢复时会更新，不沿用缓存的旧技能规则。

本目录 SKILL.md 是调用指南；sources.json 记录 16 项原版上游技能和 1 项本地 book-tutor 适配的来源、固定提交、许可和文件哈希。原来的三项图解技能继续按课程隔离。

生成提示将这些技能的教学方法置于旧策略、固定文风和默认节奏之上；旧策略强制出题、问号限制和固定内容块已在技能模式中让位；来源核验、工具权限、已登记问题真实性和正式状态写入权限保留。原版技能未改写，缺少的外部平台能力按总指南映射到实际可用工具，不声称存在 Hermes workflow 或 Learning Commons 服务。

已接入 LocalAgentLoop、ResponseGenerator（含社交回复）、PDF 选区解释和练习提示/讲解。正式练习评分不由技能替代。直接复用已保存结果或固定问题的路径不会额外启动模型。
