# exam-review（项目适配版）

读取宿主已有错题、疑问和复习记录；没有记录时明确请学生指定要复习的内容，不编造历史错题。优先处理尚未解决或需要重新验证的内容，展示原题所必需的图表，不把答案图当题面。让学生重做或复述，实际等待回答；根据独立作答、提示程度和具体理由给出反馈，不能凭流畅或自述更新正式掌握度。整理仍未解决的短清单和下一步建议。只有已有授权工具成功返回，才能声称已保存或更新回顾状态；缺工具则在聊天里展示待回顾清单。新内容教学交回 learn，诊断交回 universal-diagnostic-tutor。

参考上游原文保留在 references/upstream.md。该文件仅用于方法溯源，其中跨包链接和脚本不是本项目可执行步骤；以上宿主适配覆盖其存储、CLI及平台要求。来源见 teaching-skills/learning-sources.json。
