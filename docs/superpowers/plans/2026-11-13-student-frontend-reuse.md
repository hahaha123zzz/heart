## 1. 目标、范围与旧计划关系

目标：学生默认进入 DeepTutor 对话工作台；通过“我的学习”查看知识图谱、掌握路径、学习档案和记忆，并进入独立练习页面；设置仅保留实际可用的个人与学习选项。所选模块的详情、会话、菜单、弹窗、抽屉和状态界面随页面成组复用，不只移植首页截图。

优先直接使用原版组件和布局；只实现宿主身份、教材、数据与事件适配，以及原项目没有的必要业务组合。直接按已确认白灰主题与厂家布局实现，验证真实页面的响应式与可访问性；不再交付效果图或等待视觉确认。

本计划接替 2026-11-11《前端功能补齐与组件规划》中“五个目的地、继续维护原生 JS 外壳”的未来页面建设方向。白灰配色与旧方向一致，但页面组织和整组复用方式已有变化。旧计划、已完成改动和验收产物均保留，不回滚、不批量重写旧文档。

本计划不重开此前已完成的回答事件、流式渲染和教材证据工作。迁移必须保留这些行为，其实际状态以当前代码和重新建立的基线为准，不能把旧文档中的历史故障视作当前故障。

本次不包含：教师/班级管理、课程商城、多课程平台、学生自建教材库、开放注册、邮件服务、学校单点登录、替换记忆引擎、重建教材索引、无关教学算法重写或修改正式教材。知识点测评、后台评估和记忆适配属于本次范围；旧学习数据按 §5.6 空状态起步，教材资产不得删除。统一网站的登录隔离与个人模型凭据属于已确认范围，不能作为额外功能省略。

### 5.0 登录身份与个人模型凭据

统一网站必须先具备真正的登录会话和服务端身份解析。普通学生无权通过 URL、请求体或自定义 student_id 切换他人的学习记录、Key、附件或任务。旧接口参数若仍保留，必须与已认证主体核对；旧页面回退不能绕过新身份检查。现有上游账号服务如可安全复用，优先适配；否则补最小会话服务，不建立第二套互不一致的账户身份。

登录已按决定 35 选择厂家用户表、auth.json、dt_token，H 验证同一 token，student_id = username，不再重问三方案。固定教材、禁止上传通过服务端 learning_policy（material_ids、reading.allow_upload=false 等）执行，不能只隐藏菜单。

厂家账号、会话不强迁 PG；H 新增凭据、证据与任务表使用 SQLAlchemy 通用类型与索引，不扩展 SQLite 方言或 FTS5。

预置 10 个测试账号的初始化必须幂等：重复运行不增加账号、不重置密码、不清空学习记录；账号有效期使用明确的永久语义，不以极大 TTL 冒充，排查启动清理、定时回收及 worker 授权中的全部过期检查。此政策仅应用于这 10 个账号，其他历史测试账号不自动延长。初始化凭据只在受控交付中提供给用户，不写入 Git、日志、报告或效果图。

个人 Key 在服务端加密保存，加密密钥由部署环境独立提供；浏览器不持久化明文 Key，读取接口只返回脱敏信息。所有模型请求从服务器发起，不修改进程全局环境变量或共享 Provider 的默认 Key；客户端/缓存/后台任务必须按账号和凭据版本隔离，不能把某学生的 Key 用于其他学生。已发请求按当时配置完成；删除 Key 暂停未发任务，队列只存配置引用，不留已删除 Key 副本。配置恢复可用新模型继续，记录实际模型和规则版本，历史结果不重评。

学生只配置 OpenAI-compatible 生成模型。聊天、结构化知识点评估、工具调用及图片能力分别验证；评估不通过时聊天继续，评分/复评/后台评估暂停，通过后继续。连接验证区分“鉴权/基础响应通过”和“工具调用/图片能力通过”，不以拉取模型列表成功代表学习能力全部可用。题目截图必须使用已验证支持图像输入的模型；不支持时提示更换配置，不静默忽略图片。显示鉴权失败、余额不足、限流、模型不存在、超时等可行动错误，不回显密钥或供应商敏感响应。没有个人 Key 时允许阅读教材和查看已有记录，生成任务引导去模型设置；不使用项目共享 Key 自动兜底。

Base URL 属于学生输入：实施前验证 HTTPS、地址解析/重定向与请求超时，阻止访问服务器本机、内网和云元数据地址；确需内部模型时由管理员配置允许的端点。共享教材检索、Embedding 和建库继续使用项目配置，生成任务使用个人凭据；不因学生换模型重建共享索引。

### 5.2 图谱状态

教材图节点和关系来自当前发布版本的 LightRAG 数据；学生状态来自厂家最终评估结论，经同步供 H 展示。旧知识状态默认 mastery=0.5 不能当作学生已有掌握证据；历史只读归档不自动换算为当前掌握度。

使用 H 规范知识点目录，核验覆盖、缺漏由用户确认；厂家出题和评分携带稳定 ID。映射补齐并经用户确认是交付前置条件，模块分数不得摊给概念。新增稳定对应关系须区分：课程与教材版本、实体 ID、规范知识点 ID、掌握路径/目标 ID、映射依据。优先已有规范 ID；只按名称相似度不能自动确认。无对应、对应歧义与无测评证据分别保留为未知状态。

默认显示当前章节或当前概念的有界子图，支持搜索、聚焦和筛选。每次接口设置服务端上限并在截断时提示“部分显示”，不承诺全图已加载。节点详情展示已有证据、教材链接及学习/练习入口。图谱关系仅表达已核实的关系类型，未知关联不画成先修箭头。

学生端不开放手动标记已掌握；上游相应按钮和写动作须同时受宿主权限限制，不能只隐藏按钮。记忆新增/更正不能修改掌握状态或测评证据。

掌握与待复习结论统一以厂家为准，取消 H is_assessed_mastered、review_sort_key、RetentionScheduler 在新链路重新判定的要求。先核验厂家知识点判定、多次证据聚合及辅助/复评处理，缺失列缺口再请用户确认，不自行设阈值或最后一次覆盖。只有模块结果时补知识点级测评后交付。

证据保留目录、映射和评分规则版本；拆分、合并后的新节点不自动继承旧掌握结论，重新积累证据。无证据仍未知，关系与掌握不相互推导，不按实体数算全章完成率。运行时归属校验失败按 §5.4 修正或丢弃。

### 5.3 学生记忆

H 是唯一来源：PG memory_documents 保存有效正文，mem0 student_memory 提供检索候选；厂家聊天适配 H，关闭厂家独立记忆读写。先核验 entry/section 投影、稳定条目 ID 和版本，不按数组下标删除，不整篇无条件覆盖。

卡片显示自然语言及可验证分类/来源/时间，缺失不补造，隐藏 L1/L2/L3、内部文档、token、整篇编辑器。首版查看、搜索、详情、删除和添加偏好，不做单条更正。

注入前用 PG 校验候选有效性和版本；删除成功后新请求不得读取旧条目，索引延迟后台补齐，旧缓存和重试不得使条目复活，新证据仍可形成类似新记忆。PG 故障则本轮不用长期记忆，聊天继续，保留当前上下文及可读明确设置，不回退厂家记忆；恢复写入仍校验版本、删除和开关。

只自动保存有明确依据的学习信息，不把教材案例、引用、假设或第三方经历当学生事实。推断标未确认，可用于辅导，不作为事实或掌握证据。主动添加能力描述标学生自述，不覆盖测评，不当已验证能力。偏好与设置共用唯一来源，明确设置优先，本轮要求可临时覆盖，长期变更需确认。

只通过设置页明确开关可靠控制，聊天自然语言要求引导至设置。关闭时停止读取和自动写入，取消排队提取，已发提取结果丢弃不得写入；旧记忆可查看/删除，手动偏好可添加，重开不补扫关闭期间聊天。明确设置和聊天评估开关独立：关闭评估仍可适应教学，记忆开着可存学习推断，但不产生测评证据。

### 5.4 知识点评估、截图与复评

普通聊天、练习和截图均可形成评估，由厂家记录规范知识点 ID、题目/原始作答、评分依据、实际模型、目录/映射/规则版本及提示/答案查看顺序。查看答案后答对不能作为独立掌握证据；截图带答案或解题过程按辅助学习处理，需要时用同知识点新题验证。关键题干、标签、选项识别不完整先请补充，不强行评分。

聊天自动评估默认开启，提供说明、关闭开关、评分记录和复评入口。正常聊天先完成，后台静默评估不阻塞、不弹窗打断，对应消息保留可查看状态。关闭取消未发任务，已发可完成计入，旧证据保留；重开不补扫关闭期间聊天。失败不改变掌握。

每条候选作答最多一次独立评估，知识点 ID 或归属不符时用个人 Key 修正一次；仍失败就丢弃本次评测，不计分、不影响掌握、不进待确认队列，原作答保留。额外调用提前说明费用。

每条原始评分允许一次成功自动复评，使用个人 Key，申请前说明；结合上下文保留前后结论及原因，成功结果生效，由厂家重算并同步 H。服务失败可重试，同次申请去重，学生不能手改成绩。

### 5.5 后台任务与同步

先审计厂家现有队列，补最小持久化、重启恢复、幂等与账号隔离。离开页面继续，重启恢复，同结果不重复计分/记账。每账号限并发，前台交互优先、后台排队，已发请求不中断，上限核验现有机制后确定。

模型错误仅明确可重试时有限重试并遵守等待要求；可能已生成/计费但结果不明的请求不盲目重发，由学生决定。凭据删除、变更、能力暂停按 §5.0 处理，恢复可用新配置，记录实际模型和规则版本。

评分已保存时练习正常完成；同步 H 失败后台自动幂等补齐，图谱/档案标注同步待完成，不要求重新答题，不把旧状态当最新。同步厂家结论和依据，H 不另算掌握/复习。

删除新系统聊天保留已形成证据及必要作答和依据，掌握不回退，原会话入口标已删除。已建评估仍继续，任务保留必要输入，仍受 Key、评估开关、附件期限约束。删除前说明可能继续调用模型、计费及新增证据。

### 5.6 空状态起步、附件期限与回退

10 个账号空状态起步，不带入旧聊天、练习、证据、掌握、路径或自动记忆，不兼容旧聊天引用。教材正文、PDF、图裁剪、LightRAG 索引及发布版本完整保留。实施前登记具体数据与保留资产，禁止误删；幂等初始化不能清空新数据。本次回写不执行清理。

截图原图自上传起通常保留 30 天，必要文字证据继续保留。仅未完成任务确实依赖原图才延期，任务结束即清理，总保留上限自上传起 60 天；上限到期终止依赖任务并说明，不猜图片内容。界面标原图已过期，不留失效入口。

全量验收后切换旧壳下线，回退整包部署，不回滚学生数据。厂家存储与 H PG 两处一起备份并验证恢复；回滚后允许旧版暂时看不到新记录，但完整保留，修复重新上线后继续使用，不补旧版读取适配。

### 5.7 教材回答与引用

允许教材外补充讲解；教材支持的结论就近附可点击引用，补充段落明确说明，不用一条引用为整段扩展结论背书。未可靠映射内容不计入教材掌握。新引用准确定位教材版本、页码和有效区域，换版明确失效；不兼容旧聊天引用。
