# 切回原教材阅读器实施计划

日期：2026-11-22  
目标：在现有知学学生端恢复原教材阅读器，以聊天顶部“打开教材”按钮打开；打通教材阅读、选区提问和回答引用跳转，并更新本机 8000。保留当前阅读器版本用于回退。

## 现状和约束

- 原阅读器源码为 `project/integration/discrete-math-tutor/reader/src/reader.jsx`，现有构建产物位于 `frontend/pdf-reader/`。它依赖教材 `document_id`、版本、章节、页码和归一化坐标，且以 `window.TextbookPDF.mount/unmount` 暴露挂载接口。
- 当前聊天顶部按钮在 `project/vendor/DeepTutor/web/features/chat/components/ChatWorkspace.tsx`；截图最右侧为活动侧栏按钮。当前阅读材料、引用与跳转分别由 `integrations/deeptutor/course_reading.py`、`native_reader.py`、`web/lib/reading-citations.ts` 和聊天消息组件处理。
- 原 `main.py` 教材接口及 `/static` 不应直接暴露到学生浏览器；沿用当前用户认证和已授权教材范围。原计划任务五选用了厂家阅读器，本计划经用户要求调整该决定；不迁入旧聊天。
- 保持账户、个人模型配置、学习数据和教材原件。拒绝客户端提供的任意文件路径；版本不符或定位不明确时明确提示，不伪造高亮。

## 任务 0：核对接口与建立验收样本

- [ ] 记录当前活动发行和服务状态；只读检查正在运行的对话和模型能力验证，准备回退指针。
- [ ] 检查旧阅读器构建入口、PDF worker、CSS、挂载参数及卸载行为；核对当前 11 章教材 manifest、章节页码和授权实现。
- [ ] 为浏览器准备隔离测试账号、已授权章节与不可访问样本；不读取或修改真实账号的模型密钥。列明引用事件实际字段，分别覆盖页码引用和带矩形的引用。

验收：形成接口对应表，能确定文档版本、页码、页码映射及权限来源；不满足条件的引用归入“可打开但不能精确定位”或“不可用”，不得猜测。

## 任务 1：受认证保护的教材适配接口

- [ ] 在现有学生认证和权限边界内提供章节目录、指定章节的旧阅读器元数据及 PDF 文件响应；优先复用现有教材授权检查和已发布 manifest。
- [ ] 将旧格式中的 URL 指向受保护的同源接口；服务端校验章节、document_id、版本、文件来源和 PDF Range 请求。路径、标题、文档身份只来自可信 manifest。
- [ ] 选区预览复用 `knowledge/pdf_reader.py` 的服务端验证；限制矩形数量、坐标、版本与文件范围，返回可用于辅导的可信选区上下文。图像选区沿用现有视觉能力校验，不新增 OCR。
- [ ] 测试未登录、无权章节、跨用户、非法文档、错误版本、文件缺失、Range 与正确章节访问；确保错误信息可见且不泄漏文件路径。

验收：授权账号仅能获取自己的授权教材，数据和 PDF 元数据与固定教材版本一致；失败时有明确提示。

## 任务 2：接回原阅读器及“打开教材”按钮

- [ ] 将旧阅读器产物和所需 worker/CSS 以受控本地静态资源接入，保证读取、切换文档和组件卸载时不残留监听器或 PDF worker。
- [ ] 将截图最右侧活动按钮改为带文字和图标的“打开教材”；点击展开可关闭的教材阅读面板，提供章节与小节选择、页码输入、翻页和缩放。
- [ ] 在同一聊天中保持对话上下文；切换章节、关闭重开与窄屏时保持页面可操作，加载中和错误状态均有反馈。以真实教材验证中英文、跨页选区和触屏行为，保留原阅读器的复制及区域选择能力。

验收：登录后不配置模型也能打开授权教材；不同章节显示正确，关闭与重新打开不破坏聊天内容，手机和桌面无主要控件遮挡。

## 任务 3：选区提问与引用返回

- [ ] 将旧阅读器的文字及区域选区经服务端验证后传入当前聊天；使用当前教材上下文与个人模型配置，先展示选区来源和可编辑问题，由用户主动发送。验证失败不发送模型请求。
- [ ] 建立当前回答引用到旧阅读器位置的适配：以 document_id、version、页码及可核验矩形为依据；只有页码时打开对应页并说明无精确高亮；缺失、版本不匹配或权限失效时提示并保持原聊天。
- [ ] 处理打开前到达的定位请求、快速切换引用、重复点击、阅读器关闭、渲染尚未完成及跨章跳转。仅在阅读器实际定位成功后显示成功状态。
- [ ] 使用隔离账号和受控模型响应验证文字选区、区域选区、引用返回、无矩形、旧版本和未授权文档；如要进行真实模型调用，沿用本次会话用户已有授权并控制范围，不输出密钥。

验收：完成“选教材内容 → 提问 → 看到回答 → 点击引用 → 回到对应教材”的闭环；无依据的引用不会冒充精确定位。

## 任务 4：回归、发布和回退

- [ ] 运行受影响后端权限/选区测试、阅读器与聊天相关组件测试、TypeScript 检查及生产构建；修复真实缺陷，不以 mock 的成功代替后端权限或真实 PDF 检查。
- [ ] 在独立预览和真实 Chromium 中检查 11 章访问、至少两个账号的授权隔离、桌面/移动宽度、页面重开、聊天与引用；记录未覆盖的设备与实际模型限制。
- [ ] 生成独立发行快照及可验证构建，备份当前活动版本指针；校验无正在运行的对话和模型验证后切换本机 8000。启动失败自动切回上一版，不执行清库或账号初始化。
- [ ] 对实际 8000 再检查打开教材、章节切换、引用跳转与服务状态；比对账号和配置摘要，记录验收结果和回退操作。

验收：8000 实际服务通过上述检查；若核心闭环失败则恢复旧发行并报告问题，不宣称切换完成。
