# 教材文字问答与截图识别分流计划

日期：2026-11-23

## 问题和目标

在教材左栏打开时输入「科学方法的特点有哪些」，页面显示「2 附件」，随后提示截图识别暂停。代码中，沉浸式阅读会自动把当前 PDF 页的渲染图和内嵌插图加入本轮附件。同一对话的历史图片也可能被带入新一轮。截图入口只判断上下文里有没有图片，图片能力未验证时会在阅读工具执行前结束回合。截图中的附件具体来源待复现时核对。

文字提问和划词提问应先查教材原文，需要扩展范围时再做课程 RAG。只有本轮主动上传的图片或明确框选提交的图片，才进入图片能力检查。已有教材页回跳与原文高亮应继续可用。

## 任务 1：复现并确认附件来源

- [x] 对照普通文字提问、阅读器划词提问、框选图片提问。记录每条路径在请求中已有的教材文档、版本、页码、已校验选区和图片来源字段。

## 任务 2：按本轮输入分流

- [x] 在 `deeptutor/services/session/turns/executor.py` 区分本轮显式的图片附件、阅读器自动准备的图片和历史图片。用服务端已解析的来源分类，避免仅凭客户端标签、文件名或图片数量推断用户意图。
- [x] 当前页文字提问和划词提问保留教材文档、版本、页码和已核验文字。默认不渲染或挂载整页图片和内嵌插图，也不让旧截图在新文字回合重新触发识别。
- [x] 在 `integrations/deeptutor/screenshot_intake.py` 按本轮明确提交的图片触发识别。识别、费用确认和结果归属只使用当前提交的图片；仍使用现有模型与图片能力验证。主动上传、粘贴图片或提交框选时，图片能力未验证才给出相应提示。
- [x] 同步阅读提示词和附件展示。文字回合不显示自动生成的图片附件，也不提示模型「本轮已附上页面图」。历史回答及已有附件继续按原记录展示。

## 任务 3：打通教材检索和引用

- [x] 当问题明确指向当前页或划词段落时，优先用 `read_material` 读原文。需要寻找内容时，先用 `search_material` 定位，再读取命中的教材页。
- [x] 当前章节找不到足够依据时，允许使用现有课程 RAG `HeartCourseRagTool` 搜索已授权的教材范围。核对沉浸阅读模式实际可调用的工具，并在缺失时补齐受控入口。检索证据不足时如实说明。
- [x] 核对两种来源的引用标记。当前页和跨章检索的角标都应对应实际读取过的文档、版本和页码；可唯一匹配的原文继续高亮。跨章引用不得被解析成当前章的同一页码。
