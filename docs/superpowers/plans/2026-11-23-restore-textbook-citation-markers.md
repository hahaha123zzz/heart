# 回答教材引用角标修复计划

日期：2026-11-23  
关联：[切回原教材阅读器实施计划 · 任务 3](2026-11-22-restore-legacy-textbook-reader.md#任务-3选区提问与引用返回)

## 目标与范围

在知学聊天回答的对应句末恢复右上角数字角标（如 ¹、²）。点击角标，在当前聊天左栏打开这条回答实际引用的教材版本和页码；原来处于关闭状态时自动展开。保留教材在左、对话在右以及分隔条宽度记忆。本次只覆盖教材引用链路，验收范围为本机 8000。

现有实现有三处断点：旧阅读器选区接口返回的 `reference` 没有进入聊天请求；普通聊天不会自动携带沉浸式阅读的材料上下文；聊天只有对部分已生成链接的点击拦截，带材料修订号的链接目前还会被跳过。恢复角标需要同时解决证据获取、显示和定位。

## 任务 1：核对证据契约并复现问题

- [ ] 用隔离账号复现普通聊天、教材打开后提问、划选后提问三种路径，分别记录是否带了材料标识、服务端是否返回核实过的页码、回答是否渲染角标。记录脱敏字段和状态。
- [ ] 对照 `LegacyTextbook.tsx`、`legacy_reader_api.py`、`ChatStateAdapter.tsx`、`AssistantResponse.tsx`、`reading-citations.ts` 及原版 `frontend/chat-renderer.js`。确认教材 `document_id`、PDF 内容版本、原生材料 ID、原生修订号、原生定位号与 PDF 实际页码的映射；用跨章样本检查页码是否从每章重新计数。
- [ ] 优先复用现有阅读工具证据、会话快照与固定教材授权。用一条受控请求验证当前聊天模式能否启用教材查询并产出可保存的证据；若仅沉浸式模式提供这条路径，在显式教材提问中接入对应的受控阅读能力，保留当前会话，不在界面打开阅读器时全局切换聊天模式。

验收：能说明每种入口的断点，并确定一份从请求到回跳都可追踪的字段契约。

## 任务 2：把教材上下文带入提问

- [ ] 划词或框选后，将接口验证通过的文档、版本、页码、矩形与文字绑定为当前草稿的教材引用。输入区显示来源，可编辑问题或移除引用；用户点击发送才提交。普通提问在阅读器打开时可携带当前章和页作为检索范围，只有实际读取到的证据才可生成角标。阅读器关闭后普通提问不继承上次浏览位置。
- [ ] 发送时通过聊天请求与 WebSocket 传递已有阅读上下文或经验证的教材引用，明确区分浏览位置、用户选区和回答实际使用的证据。服务端重新核对用户授权、文档版本、页码和选区；不可用时提示重新选择。框选图沿用现有图片能力校验。
- [ ] 将实际发送的上下文记录到该轮已有请求快照。关闭阅读器、换章节、刷新、取消发送及重试分别核对草稿归属；重试原问题时按原快照核验来源。

验收：发送后可以查到本轮绑定的教材版本和页码；换章节后重试不会误用新章节。

## 任务 3：恢复角标并打通回跳

- [ ] 在回答渲染层复用本轮已核实的阅读工具结果和引用处理。只给能对应到本轮证据的正文引用标注可点击的行内上标，编号按首次出现顺序，同一来源可复用编号。多页引用分开显示或展开后逐页可选；代码块、数学内容和普通数字不被改写。
- [ ] 点击角标时，根据这条回答保存的材料和版本解析目标，而不是读取左栏当前章节。支持带原生材料修订号的引用，通过已授权的固定教材映射核对版本，以 PDF 实际页码定位。带可信坐标时高亮，只核实到页时跳页并标明定位精度；版本失效、目标不明或授权撤销时给出明确反馈。
- [ ] 等 PDF 完成渲染并到达目标页后再显示定位成功。覆盖阅读器关闭时点击、跨章、同一角标重复点击、快速连续点击；最后一次有效点击决定定位。历史回答只读取已保存的证据，缺失证据的旧回答保持原样。

验收：含多个教材来源的回答能逐个点回正确章节和页码，左栏换章后仍能返回原证据。

## 任务 4：端到端验收与本机更新

- [ ] 回归鉴权、版本校验、选区接口、回答渲染和点击路由。至少覆盖无证据回答、伪造页码、超范围页码、无权限及版本失效。用受控模型响应固定断言，使用真实教材 PDF 验证页码与高亮。
- [ ] 在 Chromium 跑完整流程：打开教材 → 划选或框选 → 发送 → 回答出现可点击角标 → 切换到另一章 → 点击角标回原页。再验证关闭阅读器后点角标、刷新后打开历史回答、连续多次点击、普通聊天和桌面分栏宽度记忆。真实模型验收另记使用范围和结果。
- [ ] 通过生产构建和候选环境验收后，生成独立发行包，记录上一版指针，更新本机 8000 并在实际端口重跑关键链路。关键链路或健康检查失败时恢复上一版。

完成标准：在本机 8000 的实际聊天里，回答正文出现由本轮教材证据支撑的角标，点击后可回到该证据的教材版本和页码。留存可复核的浏览器验收结果。
